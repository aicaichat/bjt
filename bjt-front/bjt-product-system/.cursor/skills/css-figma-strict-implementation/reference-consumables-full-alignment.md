# 前台 consumer 耗材页 — 全页块枚举（防漏）

用于 **Figma 严格对齐** 任务时与 `frontend/src/pages/Consumables/index.tsx`（及同域路由 `ProductLine2` / `ProductLine3` 耗材页若纳入同一稿）对照，交付 **覆盖表**。**本表不提供任何像素**；数值仅来自用户粘贴的 Dev CSS 或仓库内已入库原文。

块 ID 可按实际 TSX 大区增删；Agent 须在首次全页任务时根据当前 DOM **确认或重标**块名。

| 块 ID | 建议对应（从页面结构归纳） | 备注 |
|--------|----------------------------|------|
| **C1** | 页面根容器、主背景 / 与 `.figma-front` 主列衔接 | 须与壳层 token 一致；限域 `consumables-page--figma` |
| **C2** | 页顶标题 / 说明条（若有） | |
| **C3** | 面包屑、返回或产品线切换入口（若有） | |
| **C4** | 筛选行 / 工具条（区域、筛选、刷新、视图切换等） | 稿面控件优先 **原生 + token**，避免 Ant `Select`/`Button` 默认盒模型 |
| **C5** | Tabs / 分段导航（若稿中有） | 同上；必要时拆为自定义 tab 条 |
| **C6** | 产品列表外容器（栅格、间距、gutter） | 与 Figma 列数、gap 一致 |
| **C7** | 单张产品卡片外框（圆角、描边、阴影） | |
| **C8** | 卡片内：主图、标题、规格字段、价格、库存提示等 | |
| **C9** | 主操作区（加购、数量、详情入口等） | |
| **C10** | 空列表 / 加载中展示区域 | 尺寸与动效以稿为准；可原生化替代 Ant `Spin` 外框 |
| **C11** | 弹窗 / 抽屉 / 大图预览（若本次对齐范围包含） | |
| **C12** | 分页或无限滚动触发区（若有） | |

**产品线子路由**：`/consumables/product-line-2`、`/consumables/product-line-3` 若单独出稿，可各建 **C1–C12** 子表或在覆盖表中分行标注路由。
