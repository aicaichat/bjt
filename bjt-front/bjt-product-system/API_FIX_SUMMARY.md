# BJT API 修复总结报告

## 问题概述

**问题时间**: 2025年7月2日  
**问题描述**: 前端多个页面出现403和404错误，包括关联管理页面和备件管理页面

## 根本原因分析

### 1. API代理配置问题
- **症状**: API请求被发送到 `http://localhost:5173/wp-json/bjt/v1/...`
- **原因**: 环境变量配置使用了绝对URL而不是相对路径
- **影响**: 所有API请求绕过了Vite代理，直接请求前端服务器

### 2. 环境配置错误
```bash
# ❌ 问题配置
VITE_API_BASE_URL=http://localhost:8080/wp-json/bjt/v1

# ✅ 修复后配置  
VITE_API_BASE_URL=/wp-json/bjt/v1
```

### 3. Antd组件警告
- **问题**: Spin组件使用`tip`属性但未正确嵌套
- **修复**: 确保Spin组件正确使用嵌套模式或全屏模式
