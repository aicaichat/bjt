## 详细信息

### 问题描述

产品线列表页面(list.php)虽然使用了ob_start()开始捕获输出，但没有使用ob_get_clean()获取缓冲内容，也没有正确引用mockup-page-wrapper.php布局模板。这导致页面布局不一致，无法应用统一的页面结构和样式。

### 重现步骤

1. 查看templates/admin/product-lines/list.php源码
2. 观察文件结尾处缺少ob_get_clean()和布局模板包含
3. 打开产品线列表页面，观察页面布局与其他管理页面不一致

### 修复方案

1. 在templates/admin/product-lines/list.php文件开头添加ob_start()（如果尚未存在）
2. 在文件末尾添加`$page_content = ob_get_clean()`捕获缓冲内容
3. 引入布局模板，传递$page_content变量：`require_once PLUGIN_DIR . '/templates/admin/mockup-page-wrapper.php';`
4. 确认使用的变量名与其他页面保持一致

### 修改文件

- `templates/admin/product-lines/list.php`

### 修复代码

```php
<?php
// 文件开头处确保有：
ob_start();

// ... 原有内容 ...

// 文件末尾处添加：
$page_content = ob_get_clean();
require_once PLUGIN_DIR . '/templates/admin/mockup-page-wrapper.php';
```
