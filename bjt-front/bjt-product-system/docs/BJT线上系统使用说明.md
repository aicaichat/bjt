```

2. 选择对应产品类型菜单
3. 点击"添加新产品"
```

## 🔧 常见问题解决

### 登录问题

**问题**: 无法登录或提示密码错误
**解决方案**:
1. 检查用户名和密码是否正确（区分大小写）
2. 清除浏览器缓存和Cookie
3. 尝试使用无痕/隐私模式浏览器
4. 检查网络连接是否正常

**问题**: 登录后自动退出
**解决方案**:
1. 检查浏览器是否阻止Cookie
2. 确保浏览器JavaScript已启用
3. 尝试刷新页面重新登录

### 购物车问题

**问题**: 添加商品到购物车失败
**解决方案**:
1. 确认已正确登录
2. 检查产品库存是否充足
3. 刷新页面重试操作

**问题**: 购物车商品丢失
**解决方案**:
1. 确认使用相同账号登录
2. 避免使用多个浏览器标签页同时操作
3. 定期保存购物车（自动保存）

### 页面显示问题

**问题**: 页面显示不完整或错乱
**解决方案**:
1. 强制刷新页面（Ctrl+F5或Cmd+Shift+R）
2. 清除浏览器缓存
3. 检查浏览器兼容性（推荐Chrome最新版）
4. 关闭浏览器广告拦截插件

**问题**: 图片无法显示
**解决方案**:
1. 检查网络连接速度
2. 等待页面完全加载
3. 刷新页面重试

### 数据加载问题

**问题**: 页面加载缓慢或数据不显示
**解决方案**:
1. 检查网络连接速度
2. 等待系统响应（高峰时期可能较慢）
3. 尝试重新进入页面
4. 联系技术支持

## 🔌 API接口说明

### 认证方式

所有API请求都需要在Header中包含JWT认证信息：

```http
Authorization: Bearer <your_jwt_token>
```

获取JWT Token:
```http
POST /wp-json/jwt-auth/v1/token
Content-Type: application/json

{
    "username": "your_username",
    "password": "your_password"
}
```

### 错误码说明

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 400 | 请求参数错误 | 检查请求参数格式和必填项 |
| 401 | 未授权 | 检查JWT Token是否有效 |
| 403 | 权限不足 | 确认用户是否有权限访问 |
| 404 | 资源不存在 | 检查请求的资源ID是否正确 |
| 429 | 请求过于频繁 | 降低请求频率 |
| 500 | 服务器内部错误 | 联系技术支持 |

### 接口使用注意事项

1. **请求频率限制**
   - 普通用户：每分钟最多60次请求
   - VIP用户：每分钟最多120次请求
   - 超过限制将返回429错误

2. **数据格式**
   - 所有请求和响应均使用JSON格式
   - 日期时间格式：ISO 8601 (YYYY-MM-DDTHH:mm:ss.sssZ)
   - 金额单位：人民币（元）

3. **错误处理**
   - 所有错误响应都包含error_code和error_message
   - 建议实现统一的错误处理机制
   - 重要操作建议添加重试机制

4. **安全建议**
   - 使用HTTPS进行所有API调用
   - 妥善保管JWT Token
   - 定期更新Token
   - 敏感数据加密传输

5. **性能优化**
   - 合理使用分页参数
   - 按需请求数据
   - 实现本地缓存机制
   - 避免频繁请求相同数据
