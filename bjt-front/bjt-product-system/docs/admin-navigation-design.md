# 管理员导航系统设计

## 概述

为BJT产品管理系统设计了一个合理的管理员导航交互系统，解决了原有系统中缺少专门导航链接的问题。

## 设计特点

### 1. 侧边栏导航优化

- **层级结构**: 将用户管理相关功能整合为一个主菜单项
- **实时徽章**: 显示待审核用户数量，提供视觉提醒
- **自动更新**: 徽章数量每30秒自动刷新

```
用户管理 👥
├── 注册审核 [1]  # 红色徽章显示待审核数量
└── 用户列表
```

### 2. 页面内Tab导航

在用户管理相关页面顶部添加Tab导航，支持：
- 快速切换页面
- 显示待审核数量徽章
- 清晰的视觉反馈

### 3. 面包屑导航

所有页面都包含完整的面包屑导航：
```
首页 > 用户管理 > 注册审核
首页 > 用户管理 > 用户列表
```

### 4. 页面头部优化

- 统一的页面标题和描述
- 操作按钮（如刷新列表）
- 实时统计信息

## 技术实现

### 1. 自定义Hook: `usePendingUsersCount`

```typescript
export const usePendingUsersCount = () => {
  const [count, setCount] = useState<number>(0);
  // 每30秒自动更新
  // 提供手动刷新方法
  return { count, loading, error, refetch };
};
```

### 2. 导航组件

- `AdminSidebar`: 侧边栏导航，支持徽章显示
- `UserManagementTabs`: 用户管理页面间的Tab切换
- `AdminPageHeader`: 统一的页面头部组件

### 3. 服务层

- `registrationService`: 提供待审核用户数量API
- 自动刷新机制确保数据实时性

## 用户体验改进

### 1. 视觉提醒
- 红色徽章显示待审核数量
- 未读状态的视觉强调

### 2. 快速导航
- 侧边栏一键访问
- Tab导航快速切换
- 面包屑导航清晰定位

### 3. 实时更新
- 审核操作后自动刷新徽章
- 定时刷新确保数据准确

### 4. 操作反馈
- 审核成功/失败消息提示
- 加载状态指示
- 空状态友好提示

## 访问路径

### 主要路径
1. **侧边栏导航**: 用户管理 → 注册审核
2. **直接访问**: `/admin/registrations`
3. **Tab切换**: 用户列表页面 → 注册审核Tab

### 辅助路径
- 面包屑导航返回上级
- 页面间Tab快速切换

## 数据流

```
用户注册 → 状态为pending → 徽章计数+1 → 管理员审核 → 徽章计数-1
```

## 响应式设计

- 移动端友好的Tab导航
- 适配不同屏幕尺寸的侧边栏
- 徽章在小屏幕上的合理显示

3. **个性化**: 用户自定义导航偏好
4. **快捷键**: 键盘快捷键支持

## 总结

新的导航系统解决了原有的问题：
- ✅ 提供了专门的导航链接
- ✅ 实时显示待审核数量
- ✅ 支持快速页面切换
- ✅ 提供清晰的位置指示
- ✅ 优化了用户体验

通过合理的信息架构和交互设计，管理员可以更高效地处理用户注册审核工作。
