# 目录结构与命名规则

```text
src/i18n/locales/
├── en/
│   └── {namespace}.json
├── zh/
│   └── {namespace}.json
└── {lng}/               # ja ko fr ... vi
    └── {namespace}.json
```

统一命名空间（11 个）：

`translation, home, consumables, orderList, po, spareParts, machines, products, cart, order, login`

> 注意：所有语言都要包含同样的 namespace 文件，即使内容为空，也要占位。
