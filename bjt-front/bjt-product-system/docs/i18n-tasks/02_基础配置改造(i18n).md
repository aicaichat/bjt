# 基础配置改造（i18n）

⏱ 预计：0.5 人天

## 1. 安装依赖
```bash
npm i i18next-http-backend -S
```

## 2. 修改 `src/i18n/index.ts`
```ts
import HttpBackend from 'i18next-http-backend';

const SUPPORTED = ['en','ja','ko','fr','de','es','it','ru','pt','th','vi','zh'];

i18n
  .use(HttpBackend)
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    supportedLngs: SUPPORTED,
    fallbackLng: 'en',
    backend: { loadPath: '/locales/{{lng}}/{{ns}}.json' },
    // 其余配置保持不变
  });
```

## 3. 移除静态导入
- 删除以 `import xxTranslation from './locales/xx.json'` 形式出现的所有行。

## 4. 测试
1. `npm run dev`，默认加载英文。
2. 手动 `localStorage.setItem('i18nextLng', 'ja')` 刷新，检查是否请求 `/locales/ja/translation.json`。
