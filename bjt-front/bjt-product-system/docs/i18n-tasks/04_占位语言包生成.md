# 占位语言包生成

⏱ 预计：0.2 人天

## 目标
为 10 个新增语言创建空 JSON，占位各命名空间，确保运行期不会 404。

## 脚本示例
```bash
#!/usr/bin/env bash
set -e
BASE=src/i18n/locales
LANGS=(ja ko fr de es it ru pt th vi)
NAMESPACES=(translation home consumables orderList po spareParts machines products cart order login)

for lang in "${LANGS[@]}"; do
  for ns in "${NAMESPACES[@]}"; do
    mkdir -p "$BASE/$lang"
    FILE="$BASE/$lang/$ns.json"
    [[ -f "$FILE" ]] || echo '{}' > "$FILE"
  done
done
```

> 运行后共生成 ~110 个空文件；机器翻译脚本将自动写入内容。
