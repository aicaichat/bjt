# 机器页面 (MachinesPage) 功能覆盖对比分析

## 📋 **原始需求 vs 测试用例 vs 当前实现**

### 🎯 **核心需求源文档分析**

#### **1. 原始需求 (front-requirement.md - 第3点)**
```
产品及配件分类选择：
- 顶部导航栏和面包屑导航（首页 > 分类名称）
- 页面头部展示产品线的第一个筛选属性
- 按照列表形式展示产品，单选
- 根据账号类型展示阶梯价格，不同账号看到的价格不一样
- 销售类别账号能看到库存
- 展示：描述、产品图片、料号、产品名称、托盘尺寸、一拖数量
- 更多信息：包装尺寸、包装毛重、打托后总高度（浮层显示）
- 产品规则说明：点击后下载PDF文件
- 用户可以设置数量，添加到购物车
- 选择产品后展开一级配件，可继续选择
- 配件信息：图片、型号、料号、名称、电压、频率、托盘尺寸、一托数量
- 配件也有阶梯价格、库存、更多信息、规格PDF下载
- 选择一级配件后自动展开二级配件，最多五级
- 浮动购物车，在当前页面预览，不跳出页面
- 移动端：筛选区变为可折叠抽屉式菜单
- 产品卡片在小屏幕上自适应为单列布局
```
