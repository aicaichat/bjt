# 售后管理页面开发指南

## 1. 页面基本信息

- **页面名称**: 售后管理
- **页面路径**: templates/admin/after-sales/list.php
- **对应 Mockup**: 无专用mockup，参照其他列表页风格
- **优先级**: P2 (次要功能，有时间再实现)
- **相关子页面**:
  - **售后申请详情页面**: `after-sales/detail.php` (参照其他详情页风格)
    - 功能: 显示售后申请的详细信息，包括客户信息、问题描述、附件和反馈记录
  - **售后处理页面**: `after-sales/process.php` (参照表单页风格)
    - 功能: 处理售后申请，添加反馈、更新状态和审批退货

## 2. 数据关系

### 2.1 数据表关联
- **主表**: `wp_bjt_after_sales_requests` (售后申请表)
  - 主要字段: `id`, `customer_id`, `product_line`, `product_type`, `product_id`, `request_date`, `issue_description`, `status`
- **附件表**: `wp_bjt_after_sales_attachments` (售后申请附件表)
  - 主要字段: `id`, `request_id`, `file_name`, `file_url`, `file_type`, `upload_date`
- **反馈表**: `wp_bjt_after_sales_feedback` (售后反馈记录表)
  - 主要字段: `id`, `request_id`, `staff_id`, `feedback_content`, `feedback_date`, `status_change`

### 2.2 API 接口
- `GET /wp-json/bjt/v1/after-sales`: 获取售后申请列表
- `GET /wp-json/bjt/v1/after-sales/{id}`: 获取申请详情
- `PUT /wp-json/bjt/v1/after-sales/{id}/status`: 更新申请状态
- `POST /wp-json/bjt/v1/after-sales/{id}/feedback`: 添加反馈记录
- `PUT /wp-json/bjt/v1/after-sales/{id}/approve-return`: 审批退货
- `PUT /wp-json/bjt/v1/after-sales/{id}/close`: 关闭申请
- `POST /wp-json/bjt/v1/after-sales/upload`: 上传附件

### 2.3 字段验证规则
- `customer_id`: 必填，有效的用户ID
- `product_line`: 必填，有效的产品线标识
- `product_type`: 必填，枚举值：'host', 'accessory', 'consumable', 'spare'
- `product_id`: 必填，存在的产品ID
- `issue_description`: 必填，文本字段
- `status`: 必填，枚举值：'pending', 'processing', 'approved', 'rejected', 'closed'
