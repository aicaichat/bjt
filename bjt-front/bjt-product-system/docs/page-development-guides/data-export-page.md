# 数据导出页面开发指南

## 1. 页面基本信息

- **页面名称**: 数据导出
- **页面路径**: templates/admin/export/index.php
- **对应 Mockup**: 无专用mockup，参照表单页风格
- **优先级**: P2 (次要功能，有时间再实现)
- **注意**: 数据导出为单一功能页面，不包含独立子页面，但提供多种数据类型的导出选项

## 2. 数据关系

### 2.1 数据表关联
- **功能性页面**: 不直接编辑数据库表，但会查询多个表进行数据导出
- **可能涉及的表**:
  - `wp_bjt_product_lines`: 产品线主表
  - `wp_bjt_host_models`: 主机型号表
  - `wp_bjt_parts`: 主机料号表
  - `wp_bjt_accessory_models`: 配件型号表
  - `wp_bjt_accessories`: 配件料号表
  - `wp_bjt_consumables`: 耗材表
  - `wp_bjt_spare_parts`: 备件表
  - `wp_users`: 用户表

### 2.2 API 接口
- `POST /wp-json/bjt/v1/exports/orders`: 导出订单数据
- `POST /wp-json/bjt/v1/exports/inventory`: 导出库存数据
- `POST /wp-json/bjt/v1/exports/users`: 导出用户数据
- `POST /wp-json/bjt/v1/exports/products`: 导出产品数据
- `GET /wp-json/bjt/v1/exports/{job_id}/status`: 获取导出任务状态
- `GET /wp-json/bjt/v1/exports/{job_id}/download`: 下载导出文件

## 7. 常见问题与最佳实践

### 7.1 避免常见问题
- **性能问题**:
  - 避免在主进程中执行大数据导出
  - 避免一次性查询大量数据
  - 避免生成过大的导出文件

- **安全问题**:
  - 避免敏感数据未经授权导出
  - 避免下载链接可被未授权访问
  - 避免导出文件永久保留在服务器

- **用户体验问题**:
  - 避免导出过程无反馈
  - 避免导出失败无提示
  - 避免长时间阻塞用户界面

### 7.2 最佳实践建议
- **数据处理最佳实践**:
  - 使用后台任务处理大数据导出
  - 实现数据分批查询和处理
  - 使用流式处理生成大文件

- **安全最佳实践**:
  - 实现导出权限控制
  - 使用临时URL和有效期限制
  - 定期清理临时导出文件

- **用户体验最佳实践**:
  - 提供实时进度反馈
  - 支持导出任务后台运行
  - 导出完成后发送通知
  - 提供导出历史记录
