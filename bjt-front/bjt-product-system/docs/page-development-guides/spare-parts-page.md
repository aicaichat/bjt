# 备件管理页面开发指南

## 1. 页面基本信息

- **页面名称**: 备件管理
- **页面路径**: templates/admin/spare-parts/list.php
- **对应 Mockup**: 备件管理页面 (12.html)
- **优先级**: P1 (重要功能，应当实现)
- **相关子页面**:
  - **新增备件页面**: `spare-parts/add.php` (对应 Mockup: 13.html)
    - 功能: 创建新的备件记录，包含基础信息、规格和适用主机设置
  - **编辑备件页面**: `spare-parts/edit.php` (对应 Mockup: 13.html)
    - 功能: 编辑已有备件的信息，与新增页面结构相同但预填数据

## 2. 数据关系

### 2.1 数据表关联
- **主表**: `wp_bjt_spare_parts` (备件表)
  - **所有字段**:
    - `id`: bigint(20) - 自增主键
    - `product_line`: varchar(50) - 产品线标识
    - `app_model`: varchar(255) - 适配机型
    - `is_consumable`: tinyint(1) - 是否易损，默认值0
    - `image_url`: varchar(255) - 产品图片
    - `part_number`: varchar(100) - 料号
    - `name_cn`: varchar(255) - 中文名称
    - `name_en`: varchar(255) - 英文名称
    - `spec`: varchar(255) - 规格参数(公制)
    - `spec_imperial`: varchar(255) - 规格参数(英制)
    - `app_sn`: varchar(255) - 适配序列号
    - `package_size_cm`: varchar(100) - 包装尺寸(cm)
    - `package_size_inch`: varchar(100) - 包装尺寸(inch)
    - `net_weight_kg`: decimal(10,2) - 单件净重(kg)
    - `net_weight_lbs`: decimal(10,2) - 单件净重(lbs)
    - `gross_weight_kg`: decimal(10,2) - 包装毛重(kg)
    - `gross_weight_lbs`: decimal(10,2) - 包装毛重(lbs)
    - `pcs_per_box`: int(11) - 单箱数量
    - `required_parts`: text - 必选备件料号，多个用逗号分隔
    - `required_quantity`: text - 必选备件数量，多个用逗号分隔，与必选备件料号一一对应
    - `status`: varchar(20) - 状态，默认值'publish'
    - `created_at`: datetime - 创建时间
    - `updated_at`: datetime - 更新时间

- **关联表**: `wp_bjt_relations` (关联关系表)
  - **关键字段**:
    - `id`: bigint(20) - 自增主键
    - `product_line`: varchar(50) - 产品线标识
    - `parent_part_number`: varchar(100) - 父项料号
    - `child_part_number`: varchar(100) - 子项料号
    - `child_type`: ENUM('accessory', 'spare_part') - 子项类型：配件/备件
    - `level`: int(11) - 层级(1-5)，备件固定为1
    - `quantity`: int(11) - 数量，默认值1
    - `required_part_number`: varchar(100) - 必选备件料号
    - `required_quantity`: int(11) - 必选备件数量，默认值1
    - `menu_order`: int(11) - 同级排序，默认值0
    - `status`: varchar(20) - 状态，默认值'publish'

- **关联关系**:
  - 备件表与关联关系表通过`part_number`和`child_part_number`字段关联
  - 唯一索引：`wp_bjt_spare_parts`表中(`product_line`, `part_number`)
  - 备件可以通过关联关系表与主机型号或配件型号建立关联

### 2.2 API 接口
- `GET /wp-json/bjt/v1/spare-parts`: 获取备件列表
- `DELETE /wp-json/bjt/v1/spare-parts/{id}`: 删除备件
- `GET /wp-json/bjt/v1/spare-parts/{id}`: 获取备件详情
- `PUT /wp-json/bjt/v1/spare-parts/{id}`: 更新备件信息
- `POST /wp-json/bjt/v1/spare-parts`: 创建新备件
- `GET /wp-json/bjt/v1/host-models`: 获取主机型号列表
- `POST /wp-json/bjt/v1/upload/image`: 上传图片
- `GET /wp-json/bjt/v1/crm/spare-part-data`: 获取CRM中的备件数据

### 2.3 字段验证规则
- `product_line`: 必填，有效的产品线标识
- `part_number`: 必填，唯一值，长度不超过100个字符
- `name_cn`, `name_en`: 必填，长度不超过255个字符
- `app_model`: 可选，长度不超过255个字符
- `is_consumable`: 可选，布尔值
- `spec`, `spec_imperial`: 可选，长度不超过255个字符
- `app_sn`: 可选，长度不超过255个字符
- `image_url`: 可选，有效的URL
