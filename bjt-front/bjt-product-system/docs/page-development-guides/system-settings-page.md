# 系统设置页面开发指南

## 1. 页面基本信息

- **页面名称**: 系统设置
- **页面路径**: templates/admin/settings/index.php
- **对应 Mockup**: 无专用mockup，参照其他页面风格
- **优先级**: P2 (次要功能，有时间再实现)
- **注意**: 系统设置为单一页面，整合了多个设置组（基础信息、系统设置、邮件设置、API设置），不包含独立子页面

## 2. 数据关系

### 2.1 数据表关联
- **主表**: `wp_options` (WordPress选项表)
  - 自定义选项字段:
    - `bjt_company_name`: 公司名称
    - `bjt_contact_info`: 联系方式
    - `bjt_logo_url`: 公司logo
    - `bjt_default_language`: 默认语言
    - `bjt_payment_gateways`: 支付接口配置
    - `bjt_shipping_api_keys`: 物流API配置
    - `bjt_email_settings`: 邮件通知设置
    - `bjt_system_theme`: 系统主题设置

### 2.2 API 接口
- `GET /wp-json/bjt/v1/settings`: 获取系统设置
- `PUT /wp-json/bjt/v1/settings`: 更新系统设置
- `POST /wp-json/bjt/v1/upload/logo`: 上传公司logo
- `POST /wp-json/bjt/v1/settings/test-email`: 测试邮件配置
- `POST /wp-json/bjt/v1/settings/test-api`: 测试API连接

### 2.3 字段验证规则
- `bjt_company_name`: 必填，长度不超过255个字符
- `bjt_contact_info`: 可选，文本字段
- `bjt_logo_url`: 可选，有效的URL
- `bjt_default_language`: 必填，有效的语言代码
- `bjt_payment_gateways`: 可选，JSON格式的支付接口配置
- `bjt_shipping_api_keys`: 可选，JSON格式的物流API配置
- `bjt_email_settings`: 必填，包含SMTP配置信息
- `bjt_system_theme`: 必填，有效的主题标识符

## 7. 常见问题与最佳实践

### 7.1 避免常见问题
- **数据处理问题**:
  - 避免未经验证的设置保存
  - 避免敏感信息明文存储
  - 避免设置更新不生效

- **安全问题**:
  - 避免权限设置不当
  - 避免API密钥泄露
  - 避免文件上传漏洞

- **用户体验问题**:
  - 避免保存反馈不及时
  - 避免测试功能无响应
  - 避免设置项说明不清

### 7.2 最佳实践建议
- **数据处理最佳实践**:
  - 使用WordPress设置API
  - 实现设置的版本控制
  - 提供设置导入导出功能

- **安全最佳实践**:
  - 加密存储敏感信息
  - 实现适当的访问控制
  - 记录设置更改日志

- **用户体验最佳实践**:
  - 提供清晰的设置说明
  - 实现设置搜索功能
  - 提供设置恢复功能
  - 实现设置预览功能
