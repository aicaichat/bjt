## 3. 核心功能需求

### FR-01  用户注册与审核
| 项目 | 说明 |
|------|------|
| 场景 | 访客通过注册入口申请账号，管理员后台审核后方可登录并查看价格 |
| 表单字段 | 姓名、邮箱、密码、国家/地区、单位制（公/英制） |
| 审核操作 | 设置账号类别(C 端/经销商/销售/管理员)、关联仓库、公英制属性、客户代码 |
| 业务规则 | 未审核账号无法登录；审核通知通过邮件发送 |
| 依赖 | 无 |

### FR-02  库存同步服务
| 项目 | 说明 |
|------|------|
| 数据源 | CRM 库存 API（REST） |
| 同步策略 | ① 定时（每 1h）全量刷新 ② 关键页面缓存失效时实时拉取 |
| 展示规则 | • 销售账号：选型页实时显示各仓库库存  • 客户/经销商：仅在购物车提示库存不足 |
| 告警 | 若接口超时或库存<安全阈值触发邮件/钉钉告警 |

### FR-03  价格同步 & 管理
| 项目 | 说明 |
|------|------|
| 数据源 | CRM 价格 API（按客户代码、SKU 返回阶梯价） |
| 后台功能 | • 单账号/商品调价  • 批量上传 Excel 调价  • 系数整体调整 |
| 前端展示 | 阶梯价、折扣价、货币符号动态渲染 |

### FR-04  Checkout 双模式（PO / Order）
| 场景 | 说明 |
|------|------|
| PO 模式 | 与一期保持一致，所有用户可用 |
| Order 模式 | 仅当满足：总重 < Xkg、总价 < Y(币种)、仓库 ∈ {US, DE, AU}、无缺货商品 时按钮可点击 |
| 校验 | 不满足条件提示禁用原因 |

### FR-05  支付集成
| 维度 | 说明 |
|------|------|
| 支付方式 | PayPal、各地区公司网关（支持后台配置 API Key） |
| 账单货币 | 根据用户国家/地区自动选定（€, $, AU$, ¥） |
| 回调 | 支付成功/失败回调更新订单状态并通知用户 |

### FR-06  物流 tracking
| 功能 | 说明 |
|------|------|
| 后台录入 | 管理员在订单详情录入快递公司+单号 |
| 抓取服务 | 调用快递 API 周期性更新物流节点，刷新到用户中心 |
| 用户视图 | 订单页展示实时轨迹；支持复制单号、一键跳转快递官网 |

### FR-07  发票下载
- 订单完成状态下，用户可下载 PDF 发票；管理员可批量导出。  
- PDF 模板多语言、含公司抬头/税号，可配置页脚条款。

### FR-08  文档下载中心
- 后台配置产品型号 ↔ 文档 URL  
- 前端列表/搜索，点击跳 Lockedair 或内部下载链接。

### FR-09  退货 / RMA 工作流
| 步骤 | 描述 |
|------|------|
| 提交 | C 端用户订单页点击「退货申请」，填写原因、上传附件 |
| 分发 | 系统按仓库负责人邮件通知，并在后台生成工单 |
| 处理 | 售后人员变更工单状态：受理 → 处理中 → 完成 |
| 查询 | 用户可随时查看状态 & 留言 |

### FR-10  产品线 2/3/4 扩充
- 批量导入 SKU, 图片, PDF，确保与库存/价格接口字段一致。

### FR-11  后台增强
- 列表分页、模糊搜索、批量导入导出、完整用户管理 CRUD、角色权限配置。

### FR-12  移动端适配 & 浏览器兼容
- 响应式布局（≤768px）、触屏交互  
- 兼容 Chrome/Firefox/Safari/iOS Safari/Android Chrome
