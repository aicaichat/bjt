# BJT产品管理系统 UI 重构实施计划

基于UI重构要求，以下是详细的实施计划，包括目录结构优化、页面设计统一、功能完善和API端点规范化的具体步骤。

## 1. 目录结构优化

### 第一阶段：目录结构分析与规划
- 分析当前目录结构中的问题
  - 部分页面直接位于`templates/admin/`下
  - 部分页面已经组织在子目录中
  - 布局文件位置不统一
- 制定新的目录结构方案
  ```
  templates/
  ├── admin/
  │   ├── layout/
  │   │   ├── custom-layout.php
  │   │   ├── custom-header.php
  │   │   ├── custom-sidebar.php
  │   │   └── navigation.php
  │   ├── dashboard/
  │   │   └── index.php
  │   ├── product-lines/
  │   │   ├── list.php
  │   │   ├── edit.php
  │   │   └── add.php
  │   ├── host-models/
  │   │   ├── list.php
  │   │   ├── edit.php
  │   │   └── add.php
  │   ├── accessories/
  │   │   ├── list.php
  │   │   ├── edit.php
  │   │   └── add.php
  │   ├── parts/
  │   │   ├── list.php
  │   │   ├── edit.php
  │   │   └── add.php
  │   ├── consumables/
  │   │   ├── list.php
  │   │   ├── edit.php
  │   │   └── add.php
  │   ├── spare-parts/
  │   │   ├── list.php
  │   │   ├── edit.php
  │   │   └── add.php
  │   ├── users/
  │   │   ├── list.php
  │   │   ├── edit.php
  │   │   └── add.php
  │   └── settings/
  │       └── index.php
  ```

### 第二阶段：目录重构执行
1. 创建缺失的目录
   - `templates/admin/layout/`
   - `templates/admin/dashboard/`
   - `templates/admin/users/`
   - `templates/admin/settings/`

2. 将布局文件移动到layout目录
   - 移动`custom-layout.php`、`custom-header.php`、`custom-sidebar.php`到`layout/`

3. 重命名并移动页面文件
   - 将现有的`dashboard.php`移动到`dashboard/index.php`
   - 将产品线相关页面移动到`product-lines/`目录，重命名为标准命名
   - 对其他模块执行类似操作

4. 更新所有文件中的引用路径
   - 修改所有require/include语句中的路径
   - 修改所有资源文件(CSS/JS)的引用路径

## 2. 页面设计统一

### 第一阶段：UI样式标准化

1. 创建或更新样式变量文件
   ```php
   // 在assets/css/variables.css中定义
   :root {
     --bjt-primary: #1a3c70;
     --bjt-secondary: #4dabf7;
     --bjt-bg: #f7f9fc;
     --bjt-text-primary: #212121;
     --bjt-text-secondary: #757575;
     --bjt-border: #e0e0e0;
     --bjt-success: #4caf50;
     --bjt-warning: #ff9800;
     --bjt-error: #f44336;

     --bjt-spacing-sm: 8px;
     --bjt-spacing-md: 16px;
     --bjt-spacing-lg: 24px;
   }
   ```

2. 创建或更新组件样式文件
   - 重构`assets/css/components.css`，包含所有通用组件样式

3. 更新主样式文件
   - 重构`assets/css/admin.css`，应用统一样式规则
   - 移除冗余和重复的样式定义
   - 确保响应式设计正确实现

### 第二阶段：布局模板统一

1. 重构主布局模板
   - 更新`templates/admin/layout/custom-layout.php`
   - 确保页面结构与mockup一致

2. 更新页眉和导航组件
   - 重构`templates/admin/layout/custom-header.php`
   - 实现与mockup一致的顶部导航栏
   - 添加语言切换功能

3. 更新侧边栏组件
   - 重构`templates/admin/layout/custom-sidebar.php`
   - 实现与mockup一致的侧边菜单
   - 支持菜单折叠/展开功能

### 第三阶段：页面类型模板统一

1. 创建列表页模板
   - 实现统一的列表页布局，包括:
     - 顶部标题与操作按钮

2. 创建表单页模板
   - 实现统一的表单页布局，包括:
     - 语言切换选项卡
     - 表单分组
     - 图片上传区域

3. 创建详情页模板

     - 数据展示卡片
     - 关联数据列表
     - 操作按钮区域
