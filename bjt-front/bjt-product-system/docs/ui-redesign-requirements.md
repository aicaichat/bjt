# BJT产品管理系统 UI 重构要求

## 1. 目录结构统一

### 现有问题
- 模板文件夹组织不一致
- 资源文件位置不统一
- 命名规范混乱

### 要求
- 所有页面模板统一放置在 `templates/admin` 目录下
- 相似功能的页面放在对应子目录中（如 `templates/admin/accessories/`, `templates/admin/host-models/`）
- 统一命名规范：list.php, edit.php, add.php
- 共用布局统一使用 `templates/admin/layout/custom-layout.php`
- 资源文件统一放置在 `assets` 目录下，并按类型分类（css, js, img）

## 2. 页面设计与模拟设计一致

### 现有问题
- 当前实现与模拟设计（mockup）页面视觉效果差异大
- 配色方案不一致
- 控件样式、间距、布局不统一

### 要求
- 严格按照 mockup 设计实现所有页面
- 统一使用 mockup 中定义的颜色系统
  - 主色调：#1a3c70
  - 辅助色：#4dabf7
  - 背景色：#f7f9fc
- 组件样式与 mockup 一致
  - 侧边栏背景色、图标、文字大小
  - 卡片阴影、圆角、内边距
  - 表单控件高度、边框样式、焦点效果
  - 按钮尺寸、圆角、悬停效果
- 精确实现 mockup 中的间距、排版和布局

## 3. 功能完整性

### 要求
- 实现所有管理功能
  - 产品线管理: 列表、新增、编辑、删除 
  - 主机型号管理: 列表、新增、编辑、删除
  - 配件管理: 列表、新增、编辑、删除
  - 耗材管理: 列表、新增、编辑、删除
  - 备件管理: 列表、新增、编辑、删除
  - 用户管理: 列表、新增、编辑、删除、权限分配
  - 系统设置: 基本设置、语言切换
- 确保所有交互按照 mockup 实现
  - 表单标签设置与 mockup 一致
  - 添加/编辑表单的布局与 mockup 一致
  - 确保表单验证功能正常
  - 语言切换选项卡正常工作
  - 图片上传、预览功能正常
- 多语言支持功能正确实现
  - 每个页面支持中英双语内容编辑
  - 界面语言可切换
  - 提示信息支持多语言

## 4. API 端点规范

### 要求
- 所有数据操作通过标准化的 REST API 端点
  - 获取列表: GET `/api/v1/{resource}`
  - 获取单项: GET `/api/v1/{resource}/{id}`
  - 创建: POST `/api/v1/{resource}`
  - 更新: PUT `/api/v1/{resource}/{id}`
  - 删除: DELETE `/api/v1/{resource}/{id}`
- API 请求/响应格式统一
  - 请求格式统一为 JSON
  - 响应格式统一包含: status, message, data
  - 错误处理统一（HTTP 状态码+错误消息）
- 前端 JavaScript 与后端 API 交互统一
  - 使用一致的请求方式
  - 封装通用的 API 调用函数
  - 统一的错误处理与用户反馈

## 5. 具体页面实现要求

### 共用布局 (layout.php)
- 实现与 mockup 一致的顶部导航栏，包含：
  - 公司 logo
  - 导航菜单
  - 语言切换功能
  - 用户信息显示
- 实现与 mockup 一致的侧边栏，包含：
  - 产品分类菜单
  - 子菜单展开/折叠功能
  - 图标与文字搭配
  - 当前选中项高亮显示
- 主内容区域
  - 面包屑导航
  - 内容区域卡片样式
  - 统一的页面内边距与间距

### 数据列表页 (list.php)
- 顶部添加标题与操作按钮
- 筛选条件区域（如有）
- 表格样式与 mockup 一致，包含：
  - 表头样式
  - 行悬停效果
  - 分页控件
  - 批量操作控件
  - 操作按钮样式

### 表单页 (edit.php, add.php)
- 多语言表单控件与 mockup 一致，包含：
  - 语言切换选项卡
  - 每种语言的输入控件布局
  - 表单标签与控件样式
- 图片上传区域与 mockup 一致，包含：
  - 预览区域
  - 拖放支持
  - 上传按钮样式
  - 进度指示器
- 表单操作按钮区域与 mockup 一致

## 6. 交付标准

完整的 UI 重构应包含：
1. 所有页面目录结构统一重新组织
2. 所有页面样式与 mockup 保持一致
3. 所有功能正常工作
4. 所有 API 端点符合规范
5. 兼容性测试通过（Chrome、Firefox、Safari）
6. 响应式布局支持（适应不同屏幕尺寸）
