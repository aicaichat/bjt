## 6. 获取方法

### 方法 1: Figma Dev Mode
1. 打开 Figma 链接
2. 选中元素
3. 右侧 Inspect 面板查看尺寸
4. 导出图标: 右键 > Export > SVG

### 方法 2: Figma API (推荐)
```bash
# 获取节点详细数据
node scripts/figma-sync.js sync

# 查看缓存
node scripts/figma-sync.js cache
```

### 方法 3: 截图测量
1. Figma 中按 Ctrl+\ 进入 Dev Mode
2. 截图导入测量工具
3. 对比实际像素
