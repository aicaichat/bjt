## 🔍 问题发现

### 1. **错误的字段映射**
**问题**: 代码中使用了不存在的`bag_type`字段
- 代码中假设: `item.bag_type` 存储形状信息
- 数据库实际: 只有`item.shape`字段，`bag_type`字段不存在

**影响**: 形状筛选完全失效，导致统计错误

### 2. **复杂的app_model字段格式**
**问题**: app_model字段包含复杂的逗号分隔和引号格式
- 示例格式: `"LA-E4C,"LA-E4S V2.0""`
- 原始解析: 简单按逗号分割，没有处理引号

**影响**: 型号筛选不准确

### 3. **数值字段类型问题**
**问题**: 数据库中数值字段存储为字符串
- 示例: `width_met: "40.00"`, `thickness_met: "20.00"`
- 原始代码: 没有正确转换数值类型

**影响**: 规格筛选计算错误

// ❌ 错误的映射

### 2. **app_model解析修复**
```typescript
// ❌ 错误的解析
const appModels = (item.app_model || '').split(',').map(m => m.trim().replace(/"/g, ''));

// ✅ 正确的解析（处理前后引号）
const appModels = (item.app_model || '').split(',').map(m => m.trim().replace(/^[\"']|[\"']$/g, ''));
```

### 3. **数值解析修复**
```typescript
// ❌ 错误的数值提取
const match = String(value).match(/(\d+(?:\.\d+)?)/);
return match ? parseFloat(match[1]) : undefined;

// ✅ 正确的数值转换
const numValue = parseFloat(String(value));
return isNaN(numValue) ? undefined : numValue;
```
