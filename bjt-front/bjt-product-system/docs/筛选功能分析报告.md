# 耗材页面筛选功能分析报告

## 🔍 问题发现

### 1. 筛选数据来源不匹配
**问题描述**：
- 前端筛选选项从管理员字典API (`adminSpecificationService.getSpecifications()`) 获取
- 这些静态字典数据与实际商品数据不匹配
- 导致筛选选项显示但筛选不出结果

**影响**：
- 用户选择筛选条件后看不到对应商品
- 筛选功能失效

### 2. 字段映射混乱
**问题描述**：
根据CSV文件要求，应该使用以下字段进行筛选：

| CSV列 | 字段名 | 数据库字段 | 前端使用 | 状态 |
|-------|-------|-----------|---------|------|
| 1 | 适用机型 | `app_model` | ✅ 正确 | 修复 |
| 11 | 形状 | `shape` | ❌ 使用bag_type | 修复 |
| 3 | 材质 | `material` | ✅ 正确 | 修复 |
| 4 | 厚度/克重(公制) | `thickness_met` | ❌ 从specs获取 | 修复 |
| 6 | 膜宽(公制) | `width_met` | ❌ 从specs获取 | 修复 |
| 8 | 袋长(公制) | `length_met` | ❌ 从specs获取 | 修复 |

### 3. 筛选逻辑错误
**问题描述**：
- 硬编码形状映射不符合数据库实际值
- 数值比较逻辑有偏差
- 纸质材料重量筛选逻辑错误

## 🛠️ 修复方案

### 1. 动态生成筛选选项
```typescript
// 从实际商品数据动态生成规格筛选选项
const generateSpecOptions = (items: ConsumableProduct[]) => {
  const thicknessSet = new Set<number>();
  const weightSet = new Set<number>();
  const widthSet = new Set<number>();
  const lengthSet = new Set<number>();
  
  items.forEach(item => {
    // 厚度数据 - 优先使用数据库字段thickness_met
    if (item.thickness_met) thicknessSet.add(item.thickness_met);
    // 重量数据 - 对于纸质材料，使用thickness_met作为重量(gsm)
    if (isPaperMaterial(item.material) && item.thickness_met) {
      weightSet.add(item.thickness_met);
    } else if (item.net_weight_kg) {
      weightSet.add(item.net_weight_kg);
    }
    // 宽度数据 - 优先使用数据库字段width_met
    if (item.width_met) widthSet.add(item.width_met);
    // 长度数据 - 优先使用数据库字段length_met
    if (item.length_met) lengthSet.add(item.length_met);
  });
  
  // 转换为筛选选项格式...
};
```

### 2. 修复字段映射
```typescript
// 形状筛选 - 优先使用CSV定义的shape字段，fallback到bag_type
if (selectedShape !== 'all') {
  const itemShape = item.shape || item.bag_type || item.specs?.shape || '';
  const normalizedItemShape = itemShape.toLowerCase().replace(/\s+/g, '');
  const normalizedSelectedShape = selectedShape.toLowerCase().replace(/\s+/g, '');
  
  if (normalizedItemShape !== normalizedSelectedShape) {
    return false;
  }
}

// 厚度筛选 - 优先使用CSV定义的thickness_met字段
if (selectedThickness !== 'all') {
  const itemThickness = extractNumber(item.thickness_met) || extractNumber(item.specs?.thickness);
  const targetThickness = extractNumber(selectedThickness);
  if (itemThickness === undefined || targetThickness === undefined || 
      Math.abs(itemThickness - targetThickness) > 0.01) {
    return false;
  }
}
```

### 3. 优化筛选逻辑
```typescript
// 重量筛选 - 纸质材料使用thickness_met作为重量（gsm）
if (selectedWeight !== 'all') {
  let itemWeight;
  const material = item.material || item.specs?.material || '';
  if (isPaperMaterial(material)) {
    // 纸质材料的"重量"实际存储在thickness_met字段中（gsm）
    itemWeight = extractNumber(item.thickness_met);
  } else {
    itemWeight = extractNumber(item.net_weight_kg) || extractNumber(item.specs?.weight);
  }

}
```

## 🔧 API和数据库对应关系

### 前端筛选参数 → API参数 → 数据库字段

| 前端筛选 | API参数 | 数据库字段 | 备注 |
|---------|---------|-----------|------|
| selectedModel | model | app_model | 适用机型 |
| selectedShape | shape | shape (优先) / bag_type (fallback) | 形状 |
| selectedMaterial | material | material | 材质 |
| selectedThickness | thickness | thickness_met | 厚度(公制) |
| selectedWeight | weight | thickness_met (纸质) / net_weight_kg | 重量/克重 |
| selectedWidth | width | width_met | 宽度(公制) |
| selectedLength | length | length_met | 长度(公制) |

### 数据流向
```
数据库字段 → ConsumableProduct接口 → 本地筛选逻辑 → 显示结果
```
