## 1. 系统概述

### 1.1 项目简介

BJT产品系统是一个B2B电商平台，专为BJT公司的产品销售和管理而设计。系统支持多级产品关系管理、在线购物车、订单处理、库存管理等功能。

### 1.2 核心功能

- **🏭 产品管理**: 主机、配件、耗材、备件的层级化管理
- **🛒 购物车系统**: 支持多产品类型的购物车管理
- **📋 订单处理**: 完整的订单流程和PO单生成
- **🔐 用户管理**: 多角色用户系统和权限控制
- **🌍 多语言支持**: 中英文双语界面
- **📱 响应式设计**: 支持桌面端和移动端访问

### 1.3 用户角色

- **👤 普通用户**: 浏览产品、添加购物车、下单
- **🏢 VIP用户**: 享受特殊价格和优先服务
- **👨‍💼 销售人员**: 管理客户订单和产品信息
- **👨‍💻 管理员**: 系统全权限管理

## 4. 后端API页面

### 4.1 API架构

**基础URL**: `/wp-json/bjt/v1`  
**认证方式**: JWT Bearer Token  
**响应格式**: JSON

### 4.2 核心API模块

#### 🔐 认证API (`/auth`)

**端点列表**:
```
POST /auth/login          # 用户登录
GET  /user/me            # 获取当前用户信息
POST /auth/refresh       # 刷新token
POST /auth/logout        # 用户登出
```

**示例请求**:
```json
POST /wp-json/bjt/v1/auth/login
{
  "username": "admin",
  "password": "password123"
}
```

**响应格式**:
```json
{
  "success": true,
  "data": {
    "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "expires_in": 86400,
    "user": {
      "id": 1,
      "username": "admin",
      "role": "ADMIN",
      "region": "CN"
    }
  }
}
```

#### 🏭 主机API (`/host-parts`)

**端点列表**:
```
GET    /host-parts           # 获取主机列表
GET    /host-parts/{id}      # 获取主机详情
POST   /host-parts          # 创建主机
PUT    /host-parts/{id}     # 更新主机
DELETE /host-parts/{id}     # 删除主机
```

**查询参数**:
- `page`: 页码
- `per_page`: 每页数量
- `search`: 搜索关键词
- `product_line_id`: 产品线筛选

#### 🔧 配件API (`/accessories`)

**端点列表**:
```
GET    /accessories         # 获取配件列表
GET    /accessories/{id}    # 获取配件详情
POST   /accessories        # 创建配件
PUT    /accessories/{id}   # 更新配件
DELETE /accessories/{id}   # 删除配件
```

**特殊端点**:
```
GET /accessories/{id}/required  # 获取配件必选备件
```

#### 🧽 耗材API (`/consumables`)

**端点列表**:
```
GET    /consumables         # 获取耗材列表
GET    /consumables/{id}    # 获取耗材详情
POST   /consumables        # 创建耗材
PUT    /consumables/{id}   # 更新耗材
DELETE /consumables/{id}   # 删除耗材
```

**筛选参数**:
- `material`: 材料类型
- `thickness_min`/`thickness_max`: 厚度范围
- `width_min`/`width_max`: 宽度范围

#### 🔩 备件API (`/spare-parts`)

**端点列表**:
```
GET    /spare-parts         # 获取备件列表
GET    /spare-parts/{id}    # 获取备件详情
POST   /spare-parts        # 创建备件
PUT    /spare-parts/{id}   # 更新备件
DELETE /spare-parts/{id}   # 删除备件
```

#### 🛒 购物车API (`/cart`)

**端点列表**:
```
GET    /cart               # 获取购物车
POST   /cart/add          # 添加商品
PUT    /cart/update       # 更新数量
```

```json
  }
```

### 4.4 错误处理

**标准错误响应**:
```json
{
  "success": false,
  "message": "错误描述",
  "code": 1001,
  "details": {
    "field": "具体错误字段",
    "reason": "错误原因"
  }
}
```

**常见错误码**:
- `1001`: 认证失败
- `1002`: 权限不足
- `1003`: 参数错误
- `1004`: 资源不存在
- `1005`: 服务器内部错误

```nginx
    ssl_certificate_key /path/to/ssl/private.key;
    
    root /var/www/html;
    index index.php index.html;
    
    # 前端静态文件

        try_files $uri $uri/ /index.html;
```
