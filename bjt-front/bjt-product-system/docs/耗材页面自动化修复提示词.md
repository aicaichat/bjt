## 第一部分：核心要求

### 1.1 页面功能要求
耗材页面必须支持完整的筛选、展示和购物车功能，包括：
- **筛选功能**：适用机型、袋型、材质、厚度/克重（公制/英制）、膜宽（公制/英制）、袋长（公制/英制）
- **展示功能**：列表展示、tooltip详情、购物车展示、PO页面展示
- **交互功能**：添加购物车、规格选择、价格计算、库存显示

### 1.2 数据完整性要求
- 所有字段必须有数据可查，确保筛选项能全部有数据可选
- 价格、库存、规格、图片等字段都要有数据，且能被页面筛选项覆盖
- 支持货币符号和单位制（公制/英制）切换
- 支持多语言规格显示

### 3.1 ⭐ 前端筛选策略（借鉴备件页面成功经验）

#### 核心原则：前端筛选为主，避免频繁API调用

**✅ 成功经验移植**：
1. **产品类型不筛选列表** - 如有产品类型选择，只影响适配机型选项，不筛选耗材列表
2. **前端筛选为主** - 所有筛选条件在前端执行，性能更好
3. **筛选条件独立** - 每个筛选维度独立，不相互干扰
4. **智能单位制** - 根据用户地区智能显示对应筛选项

```typescript
// ✅ 正确：耗材页面前端筛选逻辑（基于备件页面成功经验）
const getFilteredConsumables = () => {
  console.log(`🔍 [getFilteredConsumables] 开始前端筛选:`, {
    selectedModel,
    selectedBagType,
    selectedMaterial,
    totalConsumables: consumables.length,
    strategy: 'FRONTEND_FILTERING'  // 强调前端筛选策略
  });

  if (!consumables || consumables.length === 0) {
    console.log('⚠️ [getFilteredConsumables] 没有基础数据');
    return [];
  }

  console.log('🔧 [getFilteredConsumables] 执行前端筛选逻辑...');
  
  let filteredItems = consumables;
  
  // 🔧 基础筛选：只显示发布状态的耗材
  filteredItems = consumables.filter(item => item.status === 'publish');
  console.log(`📊 [基础数据] 过滤状态: ${consumables.length} → ${filteredItems.length} 条`);
  
  // 1. ✅ 适用机型筛选（与备件页面逻辑一致）
  if (selectedModel && selectedModel !== 'all') {
    const beforeCount = filteredItems.length;
    filteredItems = filteredItems.filter(item => {
      if (!item.app_model) return false;
      
      // 支持多机型匹配（逗号分隔）
      const appModels = item.app_model.split(',').map(model => model.trim());
      const isMatched = appModels.includes(selectedModel);
      
      console.log(`🔍 [机型筛选] 耗材 ${item.part_number}: ${item.app_model} ${isMatched ? '✅匹配' : '❌不匹配'} ${selectedModel}`);
      return isMatched;
    });
    console.log(`📊 [机型筛选] ${selectedModel}: ${beforeCount} → ${filteredItems.length} 条`);
  }
  
  // 2. ✅ 袋型筛选
  if (selectedBagType && selectedBagType !== 'all') {
    const beforeCount = filteredItems.length;
    filteredItems = filteredItems.filter(item => {
      const isMatched = item.bag_type === selectedBagType;
      console.log(`🔍 [袋型筛选] 耗材 ${item.part_number}: ${item.bag_type} ${isMatched ? '✅匹配' : '❌不匹配'} ${selectedBagType}`);
      return isMatched;
    });
    console.log(`📊 [袋型筛选] ${selectedBagType}: ${beforeCount} → ${filteredItems.length} 条`);
  }
  
  // 3. ✅ 材质筛选
  if (selectedMaterial && selectedMaterial !== 'all') {
    const beforeCount = filteredItems.length;
    filteredItems = filteredItems.filter(item => {
      const isMatched = item.material === selectedMaterial;
      console.log(`🔍 [材质筛选] 耗材 ${item.part_number}: ${item.material} ${isMatched ? '✅匹配' : '❌不匹配'} ${selectedMaterial}`);
      return isMatched;
    });
    console.log(`📊 [材质筛选] ${selectedMaterial}: ${beforeCount} → ${filteredItems.length} 条`);
  }
  
  // 4. ✅ 规格范围筛选（根据用户地区智能选择字段）
  const unitSystem = getUserUnitSystem();
  
  // 厚度/克重范围筛选
  if (thicknessRange && (thicknessRange.min !== undefined || thicknessRange.max !== undefined)) {
    const beforeCount = filteredItems.length;
    const thicknessField = unitSystem === 'metric' ? 'thickness_met' : 'thickness_imp';
    
    filteredItems = filteredItems.filter(item => {
      const value = item[thicknessField];
      if (value === null || value === undefined) return false;
      
      let isMatched = true;
      if (thicknessRange.min !== undefined) isMatched = isMatched && value >= thicknessRange.min;
      if (thicknessRange.max !== undefined) isMatched = isMatched && value <= thicknessRange.max;
      
      console.log(`🔍 [厚度筛选] 耗材 ${item.part_number}: ${value} ${isMatched ? '✅匹配' : '❌不匹配'} 范围 [${thicknessRange.min}-${thicknessRange.max}]`);
      return isMatched;
    });
    console.log(`📊 [厚度筛选] ${thicknessField} [${thicknessRange.min}-${thicknessRange.max}]: ${beforeCount} → ${filteredItems.length} 条`);
  }
  
  // 膜宽范围筛选
  if (widthRange && (widthRange.min !== undefined || widthRange.max !== undefined)) {
    const beforeCount = filteredItems.length;
    const widthField = unitSystem === 'metric' ? 'width_met' : 'width_imp';
    
    filteredItems = filteredItems.filter(item => {
      const value = item[widthField];
      if (value === null || value === undefined) return false;
      
      let isMatched = true;
      if (widthRange.min !== undefined) isMatched = isMatched && value >= widthRange.min;
      if (widthRange.max !== undefined) isMatched = isMatched && value <= widthRange.max;
      
      console.log(`🔍 [膜宽筛选] 耗材 ${item.part_number}: ${value} ${isMatched ? '✅匹配' : '❌不匹配'} 范围 [${widthRange.min}-${widthRange.max}]`);
      return isMatched;
    });
    console.log(`📊 [膜宽筛选] ${widthField} [${widthRange.min}-${widthRange.max}]: ${beforeCount} → ${filteredItems.length} 条`);
  }
  
  // 袋长范围筛选
  if (lengthRange && (lengthRange.min !== undefined || lengthRange.max !== undefined)) {
    const beforeCount = filteredItems.length;
    const lengthField = unitSystem === 'metric' ? 'length_met' : 'length_imp';
    
    filteredItems = filteredItems.filter(item => {
      const value = item[lengthField];
      if (value === null || value === undefined) return false;
      
      let isMatched = true;
      if (lengthRange.min !== undefined) isMatched = isMatched && value >= lengthRange.min;

      return isMatched;
    });
    console.log(`📊 [袋长筛选] ${lengthField} [${lengthRange.min}-${lengthRange.max}]: ${beforeCount} → ${filteredItems.length} 条`);
  }
  
  console.log(`✅ [筛选完成] 最终结果: ${filteredItems.length} 条耗材`);
  return filteredItems;

// ✅ 重要：产品类型选择处理（借鉴备件页面经验）
```

### 🔧 6.1 耗材页面特有修复要点

#### ⭐ 前端筛选逻辑修复（核心策略）

**问题描述**：

- 产品类型选择可能错误地筛选耗材列表，导致数据丢失
- 筛选条件复杂时，后端处理逻辑容易出错

**问题描述**：
- 耗材需要支持厚度/克重、膜宽、袋长的范围筛选
- 每个规格都有公制和英制两套数据
- 需要根据用户地区智能显示对应单位制的筛选项

**修复策略**：
```typescript
// ✅ 正确：智能规格筛选工具函数
const buildSpecFilters = (userRegion: string, language: string) => {
  const unitSystem = (userRegion === 'na' || userRegion === 'au') ? 'imperial' : 'metric';
  
  const specFields = ['thickness', 'width', 'length'];
  
  return specFields.map(field => ({
    key: `${field}_${unitSystem === 'metric' ? 'met' : 'imp'}`,
    label: getFieldLabel(field, unitSystem, language),
    type: 'range',
    dataType: 'decimal'
  }));
};

// 执行规格筛选
const applySpecFilters = (items, filters, unitSystem) => {
  return items.filter(item => {
    for (const [field, range] of Object.entries(filters)) {
      if (range && range.min !== undefined && range.max !== undefined) {
        const value = item[`${field}_${unitSystem === 'metric' ? 'met' : 'imp'}`];
        if (value < range.min || value > range.max) {
          return false;
        }
      }
    }
    return true;
  });
};
```

```typescript
// 自动回滚监控系统
interface RollbackTrigger {
  name: string;
  condition: () => boolean;
  severity: 'critical' | 'major' | 'minor';
  autoRollback: boolean;
}

const rollbackTriggers: RollbackTrigger[] = [
  {
    name: 'API响应失败率过高',
    condition: () => getAPIErrorRate() > 0.1, // 10%错误率
    severity: 'critical',
    autoRollback: true
  },
  {
    name: '页面加载时间过长',
    condition: () => getPageLoadTime() > 5000, // 5秒
    severity: 'major',
    autoRollback: true
  },
  {
    name: '筛选功能失效',
    condition: () => !testFilterFunctionality(),
    severity: 'critical',
    autoRollback: true
  },
  {
    name: '购物车功能异常',
    condition: () => !testCartFunctionality(),
    severity: 'major',
    autoRollback: true
  },
  {
    name: '数据显示错误',
    condition: () => !validateDataIntegrity(),
    severity: 'major',
    autoRollback: false // 需要人工确认
  }
];

// 监控循环
const startRollbackMonitoring = () => {
  console.log('🔍 开始升级后监控...');
  
  const monitoringInterval = setInterval(() => {
    rollbackTriggers.forEach(trigger => {
      try {
        if (trigger.condition()) {
          console.error(`❌ 检测到问题: ${trigger.name}`);
          
          if (trigger.autoRollback && trigger.severity === 'critical') {
            console.log('🔙 触发自动回滚...');
            executeRollback(trigger.name);
            clearInterval(monitoringInterval);
          } else {
            sendAlert(trigger);
          }
        }
      } catch (error) {
        console.error(`监控异常: ${trigger.name}`, error);
      }
    });
  }, 30000); // 每30秒检查一次
  
  // 监控24小时后自动停止
  setTimeout(() => {
    clearInterval(monitoringInterval);
    console.log('✅ 升级监控期结束');
  }, 24 * 60 * 60 * 1000);
};
```

```bash
#!/bin/bash
```

```bash
handle_emergency() {
  local SEVERITY=$1

  echo "🚨 [$TIMESTAMP] 故障级别: $SEVERITY - $ISSUE"
```
