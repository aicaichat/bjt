# 购物车多语言问题解决方案

## 🎯 问题描述

用户反馈购物车页面在英文环境下显示的产品名称仍然是中文，需要实现真正的多语言支持。

## 🔍 问题分析

### 前端多语言系统 ✅ 正常
- API请求正确传递 `{"lang":"zh"}` 或 `{"lang":"en"}` 参数
- 前端界面翻译系统工作正常
- 语言切换功能正常

### 后端API多语言基础设施 ✅ 正常  
- `get_product_name_image()` 函数能够接收和处理语言参数
- API路由和参数传递正确

### 数据库内容问题 ❌ 需要处理
**根本问题**：数据库表中的 `name_zh` 和 `name_en` 字段内容相同，都包含中文

从控制台日志可以看到：
```
name: "LA-E4S(paper)主机-标准版"
name_en: "LA-E4S(paper)主机-标准版"  // 应该是英文，但实际是中文
name_zh: "LA-E4S(paper)主机-标准版"  // 正确的中文
```

## 🛠️ 解决方案

### 后端API修改

修改 `plugins/bjt-core-entities/controllers/class-cart-controller.php` 中的 `get_product_name_image` 函数：

```php
protected function get_product_name_image($part_number, $product_type, $lang = 'zh') {
    // ... 数据库查询代码 ...
    
    if ($product) {
        if ($lang === 'zh') {
            // 中文请求：返回中文名称
            $name = $product->name_zh ?? 'Name N/A';
        } else {
            // 英文请求：优先使用英文名称，如果没有或与中文相同则生成英文标题
            if (!empty($product->name_en) && $product->name_en !== $product->name_zh) {
                $name = $product->name_en;
            } else {
                $name = $this->get_english_title($product->name_zh ?? 'Name N/A', $product_type);
            }
        }
        
        return [
            'name' => $name, 
            'image_url' => $product->$image_col ?? null
        ];
    }
    return ['name' => 'Not Found', 'image_url' => null];
}

/**
 * 生成英文标题（简化版本）
 */
private function get_english_title($chinese_name, $product_type) {
    // 基本的关键词翻译
    $translations = [
        '主机' => 'Host',
        '标准版' => 'Standard',
        '高级版' => 'Advanced',
        '专业版' => 'Professional',
        '气垫膜' => 'Air Bubble Film',
        '封口机' => 'Sealing Machine',
        '打包机' => 'Packaging Machine',
        '配件' => 'Accessory',
        '备件' => 'Spare Part',
        '耗材' => 'Consumable',
        '设备' => 'Equipment',
        '机器' => 'Machine'
    ];
    
    $english_name = $chinese_name;
    
    // 执行关键词替换
    foreach ($translations as $chinese => $english) {
        $english_name = str_replace($chinese, $english, $english_name);
    }
    
    // 如果没有翻译发生，保持原名称
    return $english_name;
}
```

## 🎯 解决方案特点

### ✅ 正确的语言处理逻辑
- **中文请求** (`lang=zh`)：始终返回 `name_zh` 字段内容
- **英文请求** (`lang=en`)：
  1. 优先使用 `name_en` 字段（如果与 `name_zh` 不同）
  2. 如果 `name_en` 为空或与 `name_zh` 相同，则自动生成英文标题

### ✅ 智能英文标题生成
- 对常见中文关键词进行英文替换
- 保持产品型号和特殊标识不变
- 避免过度翻译导致的信息丢失

### ✅ 向后兼容
- 不影响现有的中文显示
- 不需要修改前端代码
- 不需要修改数据库结构

## 📊 测试结果

|------------|-------------|-------------|------|
