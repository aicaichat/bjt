# 单位制智能切换实现方案

## 🎯 智能单位制目标

基于现有的 `useAuth().getPreferredUnit()` 用户偏好设置，实现购物车系统中重量、尺寸、长度等字段的智能公制/英制自动切换。

**核心原则**：
- 单位信息显示在标签中，数值保持纯净
- 完全基于用户账户设置，无手动切换功能
- 与备件页面、耗材页面保持一致的实现方式

## 📋 正确的显示格式

### ✅ 正确格式
```
标签：Package Size(cm):     数值：40*34.5*39
标签：Pallet Size(cm):      数值：100*120
标签：Net Weight(kg):       数值：25.5

用户设置为英制后：
标签：Package Size(inch):   数值：15.7*13.6*15.4
标签：Pallet Size(inch):    数值：39.4*47.2
标签：Net Weight(lbs):      数值：56.2
```

### ❌ 错误格式（当前实现）
```
标签：Package Size:         数值：40*34.5*39cm
标签：Pallet Size:          数值：100*120cm
标签：Net Weight:           数值：25.5kg
```

## 🔧 基于用户账户设置的智能单位制

### 核心实现策略
直接使用现有的 `useAuth().getPreferredUnit()` 接口，基于用户账户中的 `preferred_unit` 字段进行智能字段映射，与备件页面、耗材页面保持完全一致的实现方式。

```typescript
// 简化的智能单位制Hook - 基于用户账户设置
import { useAuth } from '../contexts/AuthContext';

export const useSmartUnitSystem = () => {
  const { getPreferredUnit } = useAuth();
  
  // 直接基于用户账户设置的单位制偏好
  const preferredUnitSystem = useMemo((): 'metric' | 'imperial' => {
    const authPreference = getPreferredUnit?.();
    if (authPreference && ['metric', 'imperial'].includes(authPreference)) {
      return authPreference as 'metric' | 'imperial';
    }
    
    // 默认值：全球默认使用公制
    return 'metric';
  }, [getPreferredUnit]);
  
  return {
    preferredUnitSystem,
    accountUnitSetting: getPreferredUnit?.() || 'metric'
  };
};
```

## 🎯 智能标签和字段映射实现

### 核心实现策略
1. **智能标签生成**：根据用户单位制偏好动态生成带单位的标签
2. **智能字段映射**：根据用户单位制偏好选择正确的数据字段
3. **纯净数值显示**：字段值不包含单位信息

### 智能标签生成Hook
```typescript
export const useSmartFieldLabels = () => {
  const { preferredUnitSystem } = useSmartUnitSystem();
  const { t } = useTranslation();
  
  // 生成带单位的智能标签
  const getSmartLabel = useCallback((baseKey: string): string => {
    const baseLabel = t(`products.properties.${baseKey}`, baseKey);
    const fieldConfig = CART_FIELD_CONFIGS[baseKey];
    
    if (!fieldConfig?.unitConfig) {
      return baseLabel; // 无单位制配置的字段直接返回基础标签
    }
    
    // 获取当前单位制对应的单位
    const unit = getFieldUnit(fieldConfig.unitConfig[preferredUnitSystem]);
    
    return unit ? `${baseLabel}(${unit})` : baseLabel;
  }, [preferredUnitSystem, t]);
  
  return { getSmartLabel, preferredUnitSystem };
};
```

### 智能字段映射Hook
```typescript
export const useSmartFieldMapping = () => {
  const { preferredUnitSystem } = useSmartUnitSystem();
  
  // 根据用户偏好自动选择字段
  const getSmartFieldMapping = useCallback((fieldKey: string, product: any) => {
    const fieldConfig = CART_FIELD_CONFIGS[fieldKey];
    if (!fieldConfig?.unitConfig) return fieldKey;
    
    const isImperial = preferredUnitSystem === 'imperial';
    const targetField = isImperial ? 
      fieldConfig.unitConfig.imperial : 
      fieldConfig.unitConfig.metric;
    
    // 检查目标字段是否存在且有值
    if (product[targetField] !== undefined && 
        product[targetField] !== null &&
        product[targetField] !== '') {
      return targetField;
    }
    
    // 如果目标字段不存在，尝试另一个单位制的字段
    const fallbackField = isImperial ? 
      fieldConfig.unitConfig.metric : 
      fieldConfig.unitConfig.imperial;
    
    if (product[fallbackField] !== undefined && 
        product[fallbackField] !== null &&
        product[fallbackField] !== '') {
      return fallbackField;
    }
    
    // 都不存在则返回基础字段名
    return fieldKey;
  }, [preferredUnitSystem]);
  
  return { getSmartFieldMapping, preferredUnitSystem };
};
```

## 🔄 单位制转换规则

### 重量转换
```typescript
export const WEIGHT_CONVERSIONS = {
  // 公制到英制
  kg_to_lbs: (kg: number): number => kg * 2.20462,
  g_to_oz: (g: number): number => g * 0.035274,
  
  // 英制到公制
  lbs_to_kg: (lbs: number): number => lbs / 2.20462,
  oz_to_g: (oz: number): number => oz / 0.035274,
  
  // 格式化
  formatWeight: (value: number, unit: string): string => {
    if (unit === 'kg' || unit === 'lbs') {
      return value.toFixed(2);
    }
    return value.toFixed(1);
  }
};
```

### 尺寸转换
```typescript
export const DIMENSION_CONVERSIONS = {
  // 长度转换
  cm_to_inch: (cm: number): number => cm / 2.54,
  inch_to_cm: (inch: number): number => inch * 2.54,
  m_to_ft: (m: number): number => m * 3.28084,
  ft_to_m: (ft: number): number => ft / 3.28084,
  
  // 复合尺寸转换
  convertCompositeDimension: (
    value: string, 
    fromUnit: 'cm' | 'inch'
  ): { value: string; unit: 'cm' | 'inch' } => {
    if (!value || typeof value !== 'string') {
      return { value: '', unit: fromUnit };
    }
    
    // 解析复合尺寸（如 "75*35*45" 或 "29.5*13.8*17.7"）
    const dimensions = value.split(/[*×x]/).map(d => parseFloat(d.trim()));
    if (dimensions.some(isNaN)) {
      return { value, unit: fromUnit };
    }
    
    const targetUnit = fromUnit === 'cm' ? 'inch' : 'cm';
    const converter = fromUnit === 'cm' ? 
      DIMENSION_CONVERSIONS.cm_to_inch : 
      DIMENSION_CONVERSIONS.inch_to_cm;
    
    const convertedDimensions = dimensions.map(d => 
      Number(converter(d).toFixed(1))
    );
    
    return {
      value: convertedDimensions.join('*'),
      unit: targetUnit
    };
  },
  
  // 格式化
  formatDimension: (value: number, unit: string): string => {
    return value.toFixed(1);
  }
};
```

### SmartFieldValue 组件（纯净数值）
```typescript
export const SmartFieldValue: React.FC<{
  product: any;
  fieldKey: string;
  precision?: number;
  className?: string;
}> = React.memo(({ 
  product, 
  fieldKey, 
  precision = 2,
  className = ''
}) => {
  const { getSmartFieldMapping, preferredUnitSystem } = useSmartFieldMapping();
  
  // 使用 useMemo 确保当单位制变化时重新计算
  const { targetField, rawValue, displayValue } = useMemo(() => {
    const targetField = getSmartFieldMapping(fieldKey, product);
    const rawValue = product[targetField];
    
    // 如果没有值，返回空
    if (rawValue === undefined || rawValue === null || rawValue === '') {
      return { targetField, rawValue, displayValue: '-' };
    }
    
    // 显示纯净数值（不包含单位）
    let displayValue: string;
    if (typeof rawValue === 'number') {
      displayValue = rawValue.toFixed(precision);
    } else if (typeof rawValue === 'string') {
      // 处理字符串类型的数据
      if (rawValue === 'N/A' || rawValue.toLowerCase() === 'n/a') {
        displayValue = 'N/A';
      } else {
        displayValue = rawValue;
      }
    } else {
      displayValue = String(rawValue);
    }
    
    return { targetField, rawValue, displayValue };
  }, [fieldKey, product, precision, getSmartFieldMapping, preferredUnitSystem]);
  
  return (
    <span 
      className={`smart-field-value ${className}`} 
      data-field={targetField}
      data-unit-system={preferredUnitSystem}
      key={`${fieldKey}-${preferredUnitSystem}-${targetField}`}
    >
      {displayValue}
    </span>
  );
});
```

## 🎯 关键实现要点

### ✅ 正确的实现方式
- **基于用户账户设置**：直接使用 `useAuth().getPreferredUnit()` 获取用户偏好
- **标签包含单位**：`Package Size(cm):` 
- **数值保持纯净**：`40*34.5*39`
- **智能字段选择**：根据用户单位制偏好选择 `package_size_cm` 或 `package_size_inch`
- **自动响应变化**：用户修改账户设置后，所有页面自动更新

### ❌ 避免的错误方式
- 在数值后面添加单位：`40*34.5*39cm`
- 标签和数值单位不匹配
- 硬编码单位制选择
- 单位重复显示
- 提供手动切换功能（与其他页面不一致）

## 🔧 核心原理

1. **基于用户设置**：`getPreferredUnit()` → `"metric"` 或 `"imperial"`
2. **智能标签生成**：`getSmartLabel('net_weight')` → `"Net Weight(kg):"` 或 `"Net Weight(lbs):"`
3. **智能字段映射**：`getSmartFieldMapping('net_weight', product)` → `"net_weight_kg"` 或 `"net_weight_lbs"`
4. **纯净数值显示**：直接显示字段值，不添加任何单位后缀
5. **自动响应更新**：用户在个人设置页面修改偏好后，所有页面自动更新

### 耗材页面实现方式
```typescript
// 耗材页面中的实现
const { getPreferredUnit } = useAuth();
const preferred_unit = getPreferredUnit(); // 获取偏好单位制

const getSmartUnitValue = (item: any, fieldKey: string): string => {
  const unitConfig = CONSUMABLE_DISPLAY_CONFIG.UNIT_FIELDS[fieldKey];
  if (!unitConfig) {
    return item[fieldKey] || '';
  }
  
  // 基于用户单位制偏好，而非地区判断
  const isImperial = preferred_unit === 'imperial';
  const targetField = isImperial ? unitConfig.imperial : unitConfig.metric;
  const primaryValue = item[targetField];
  
  return primaryValue || '';
};
```

### 购物车页面实现方式（现在）
```typescript
// 购物车页面中的实现 - 与其他页面完全一致
const { preferredUnitSystem } = useSmartUnitSystem(); // 内部使用 getPreferredUnit()

const getSmartFieldMapping = (fieldKey: string, product: any) => {
  const fieldConfig = CART_FIELD_CONFIGS[fieldKey];
  if (!fieldConfig?.unitConfig) return fieldKey;
  
  const isImperial = preferredUnitSystem === 'imperial';
  const targetField = isImperial ? 
    fieldConfig.unitConfig.imperial : 
    fieldConfig.unitConfig.metric;
  
  return targetField;
};
```

## 🔄 如何修改单位制偏好

用户需要前往**个人设置页面**（Profile页面）修改单位制偏好：

1. 登录系统
2. 进入个人设置页面
3. 在"单位制偏好"部分选择：
   - **公制 (Metric)**：厘米、千克、摄氏度
   - **英制 (Imperial)**：英寸、磅、华氏度
4. 保存设置
5. 系统自动应用到所有页面（购物车、备件、耗材等）

这个方案确保了单位信息的清晰展示，避免了单位重复和混乱，与整个系统的其他页面保持完全一致的用户体验。
