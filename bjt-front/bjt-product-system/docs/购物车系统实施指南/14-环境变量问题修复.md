# 环境变量问题修复 - process is not defined

> **问题解决！** 成功修复了 Vite 环境中的 `process is not defined` 错误，系统现已正常运行。

## 🐛 问题描述

**错误信息**:
```
Uncaught ReferenceError: process is not defined
    at feature-flags.ts:4:22
```

**问题原因**:
在 Vite 项目中使用了 `process.env` 来访问环境变量，但 Vite 使用 `import.meta.env` 而不是 `process.env`。

## 🔧 解决方案

### 1. 修复核心配置文件

#### feature-flags.ts
```typescript
// ❌ 修复前 (错误用法)
SMART_UNIT_SYSTEM: process.env.REACT_APP_ENABLE_SMART_UNITS === 'true',

// ✅ 修复后 (正确用法)  
SMART_UNIT_SYSTEM: import.meta.env.VITE_ENABLE_SMART_UNITS === 'true',
```

#### machine-display-config.ts
```typescript
// ❌ 修复前
ENABLE_DEBUG_INFO: process.env.NODE_ENV === 'development',

// ✅ 修复后
ENABLE_DEBUG_INFO: import.meta.env.DEV,
```

#### mock-config.ts
```typescript
// ❌ 修复前
const isDevelopment = process.env.NODE_ENV === 'development';

// ✅ 修复后
const isDevelopment = import.meta.env.DEV;
```

### 2. 环境变量命名修改

**Vite 要求环境变量以 `VITE_` 开头**:

| 修复前 | 修复后 |
|-------|--------|
| `REACT_APP_ENABLE_SMART_UNITS` | `VITE_ENABLE_SMART_UNITS` |
| `REACT_APP_ENABLE_CART_ENHANCEMENT` | `VITE_ENABLE_CART_ENHANCEMENT` |
| `REACT_APP_DEBUG` | `VITE_DEBUG` |
| `NODE_ENV` | `import.meta.env.DEV/PROD/MODE` |

### 3. 创建正确的环境变量配置

**文件**: `frontend/.env.development`
```bash
VITE_ENABLE_SMART_UNITS=true
VITE_ENABLE_CART_ENHANCEMENT=true
VITE_DEBUG=true
VITE_ENABLE_MACHINE_STANDARD_DISPLAY=true
VITE_ENABLE_SMART_UNIT_SYSTEM=true
VITE_ENABLE_PERF_MONITORING=true
```

## 🎯 Vite 环境变量最佳实践

### 1. 命名规范
- **客户端变量**: 必须以 `VITE_` 开头
- **服务端变量**: 无需前缀，仅在构建时可用

### 2. 访问方式
```typescript
// ✅ 正确方式
import.meta.env.VITE_API_URL
import.meta.env.DEV          // 开发环境
import.meta.env.PROD         // 生产环境  
import.meta.env.MODE         // 当前模式

// ❌ 错误方式 (在 Vite 中)
process.env.NODE_ENV
process.env.REACT_APP_API_URL
```

### 3. 类型安全
```typescript
// vite-env.d.ts 中定义类型
interface ImportMetaEnv {
  readonly VITE_ENABLE_SMART_UNITS: string
  readonly VITE_ENABLE_CART_ENHANCEMENT: string
  readonly VITE_DEBUG: string
}

interface ImportMeta {
  readonly env: ImportMetaEnv
}
```
