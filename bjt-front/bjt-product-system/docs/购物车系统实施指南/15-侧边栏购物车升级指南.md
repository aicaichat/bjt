# 侧边栏购物车升级指南

## 🎯 升级概述

侧边栏购物车升级为智能版本，**保持原有的样式和行为不变**，仅在字段显示上基于用户账户设置自动选择对应的单位制字段，与备件页面、耗材页面的实现方式完全一致。

## 📊 影响范围分析

### 受影响的页面
侧边栏购物车是全局组件，在以下页面中使用：

1. **所有产品页面** - 机器、耗材、备件、配件页面
2. **主页面** - App.tsx 中的全局侧边栏
3. **搜索页面** - 搜索结果页面
4. **分类页面** - 产品分类浏览页面

### 核心文件
- `frontend/src/components/Cart/CartSidebar.tsx` - 原始侧边栏
- `frontend/src/components/Cart/EnhancedCartSidebar.tsx` - 增强版侧边栏
- `frontend/src/components/Cart/CartSidebar.css` - 样式文件
- `frontend/src/App.tsx` - 主应用入口

## 🚀 升级方案

### 方案一：渐进式升级（推荐）

通过功能开关控制，可以随时在原版和增强版之间切换：

```typescript
// App.tsx 中的条件渲染
{FEATURE_FLAGS.CART_FIELD_ENHANCEMENT ? (
  <EnhancedCartSidebar isOpen={isCartOpen} onClose={closeCart} />
) : (
  <CartSidebar isOpen={isCartOpen} onClose={closeCart} />
)}
```

**优势**：
- ✅ 零风险升级
- ✅ 可随时回滚
- ✅ 支持A/B测试
- ✅ 渐进式部署

### 方案二：直接替换

直接用增强版替换原版组件：

```typescript
// 直接导入增强版
import EnhancedCartSidebar from './components/Cart/EnhancedCartSidebar';

// 使用增强版
<EnhancedCartSidebar isOpen={isCartOpen} onClose={closeCart} />
```

**优势**：
- ✅ 实现简单
- ✅ 代码更清洁

**风险**：
- ⚠️ 无法快速回滚
- ⚠️ 需要充分测试

## 🎯 新增功能

### 1. 智能单位制自动切换

**功能描述**：
- 基于用户账户中的 `preferred_unit` 设置自动显示对应单位制的字段
- **保持原有界面样式**，不添加任何新的UI元素
- 与备件页面、耗材页面保持完全一致的实现方式
- 无手动切换功能，完全基于用户偏好自动适配

**界面外观**：
```
购物车 [×]  (保持原样，无任何新增元素)
```

**自动切换逻辑**：
1. 读取用户账户设置中的 `preferred_unit` 字段
2. 根据设置自动显示对应单位制的字段
3. 公制用户：显示 `net_weight_kg`、`package_size_cm`、`spec` 等
4. 英制用户：显示 `net_weight_lbs`、`package_size_inch`、`spec_imperial` 等
5. 用户修改账户设置后，所有页面自动更新

### 2. 增强字段显示

**智能字段映射**：
- 根据用户单位制偏好自动选择对应字段
- 公制模式：优先显示 `_kg`、`_cm` 后缀字段
- 英制模式：优先显示 `_lbs`、`_inch` 后缀字段
- 备件规格：公制显示 `spec`，英制显示 `spec_imperial`

**字段优先级**：
1. 优先显示用户偏好单位制对应字段
2. 如果不存在，显示另一单位制字段
3. 都不存在则不显示该字段

**支持的字段类型**：
- **重量字段**：`net_weight_kg` / `net_weight_lbs`
- **尺寸字段**：`package_size_cm` / `package_size_inch`
- **托盘字段**：`pallet_size_cm` / `pallet_size_inch`
- **规格字段**：`spec` / `spec_imperial`
- **通用字段**：`voltage`、`app_model` 等（无单位制区别）

## 🔧 核心优势

### ✅ 零界面变化
- **完全保持原有样式**：不添加任何新的按钮、指示器或UI元素
- **行为一致性**：所有交互行为与原版完全相同
- **视觉无感知**：用户看不到任何界面变化，只是数据更智能

### ✅ 智能数据适配
- **自动单位制**：根据用户偏好自动显示合适的字段
- **无需手动操作**：用户无需任何额外操作
- **全系统一致**：与备件、耗材页面保持完全一致

## 📈 预期效果

### 用户体验提升

1. **便捷性**：无需进入设置即可切换单位制
