## 🔧 核心特性

### 智能单位制系统 🎯
- **自动适配** - 基于用户账户偏好自动选择单位制
- **临时切换** - 支持页面级临时单位制切换
- **优先级控制** - 手动设置 > 账户偏好 > 默认公制

- **51个智能字段** - 覆盖机器、耗材、备件、配件四类产品
- **多语言标签** - 准确的中英文字段标签系统

```bash

cp docs/购物车系统实施指南/env-config-examples.md frontend/.env.development

# 编辑配置启用功能 (开发环境建议全部开启)
# REACT_APP_ENABLE_SMART_UNITS=true
# REACT_APP_ENABLE_CART_ENHANCEMENT=true  
# REACT_APP_DEBUG=true
```

