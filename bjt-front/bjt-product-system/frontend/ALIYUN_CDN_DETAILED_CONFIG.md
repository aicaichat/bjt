# 阿里云CDN详细配置指南 - 解决购物车缓存问题

## 🎯 **配置目标**
让购物车、认证、订单等动态API完全绕过CDN缓存，确保数据实时性。

---

## **📱 详细操作步骤**

### **第1步：登录阿里云控制台**

1. 访问：https://cdn.console.aliyun.com/
2. 登录你的阿里云账号
3. 在域名列表中找到 `eorder.lockedair.com`
4. 点击域名进入管理页面

### **第2步：配置缓存规则（重点）**

#### **2.1 进入缓存规则页面**
```
左侧菜单：缓存配置 → 缓存规则
```

#### **2.2 添加购物车API不缓存规则**
```
点击右上角"添加"按钮

配置项填写：
┌─────────────────────────────────────┐
│ 规则类型: ○ 文件 ● 目录 ○ 文件扩展名  │
│ 规则内容: /wp-json/bjt/v1/cart      │
│ 缓存时间: 不缓存                     │
│ 优先级:   10                       │
│ 权重:     1                        │
└─────────────────────────────────────┘

点击"确定"保存
```

#### **2.3 重复添加其他动态API规则**

**认证API规则：**
```
规则类型: 目录
规则内容: /wp-json/bjt/v1/auth
缓存时间: 不缓存
优先级: 9
```

**订单API规则：**
```
规则类型: 目录  
规则内容: /wp-json/bjt/v1/order
缓存时间: 不缓存
优先级: 8
```

**用户API规则：**
```
规则类型: 目录
规则内容: /wp-json/bjt/v1/user  
缓存时间: 不缓存
优先级: 7
```

**登录API规则：**
```
规则类型: 目录
规则内容: /wp-json/bjt/v1/login
缓存时间: 不缓存
优先级: 6
```

#### **2.4 添加产品API短期缓存规则**
```
规则类型: 目录
规则内容: /wp-json/bjt/v1/machines
缓存时间: 5分钟
优先级: 5

规则类型: 目录
规则内容: /wp-json/bjt/v1/accessories  
缓存时间: 5分钟
优先级: 4

规则类型: 目录
规则内容: /wp-json/bjt/v1/consumables
缓存时间: 5分钟
优先级: 3
```

### **第3步：配置HTTP头管理**

#### **3.1 进入HTTP头管理页面**
```
左侧菜单：高级配置 → HTTP头管理
```

#### **3.2 为购物车API添加响应头**

**添加Cache-Control头：**
```
点击右上角"添加"按钮

配置项填写：
┌─────────────────────────────────────┐
│ 规则类型: ● 目录 ○ 文件 ○ 文件扩展名  │
│ 规则内容: /wp-json/bjt/v1/cart      │
│ 操作:     ● 设置 ○ 删除 ○ 替换      │
│ HTTP头名称: Cache-Control            │
│ HTTP头值: no-cache, no-store, must-revalidate │
│ 是否允许重复: ○ 是 ● 否              │
│ 优先级: 10                          │
└─────────────────────────────────────┘

点击"确定"保存
```

**添加Pragma头：**
```
规则类型: 目录
规则内容: /wp-json/bjt/v1/cart
操作: 设置
HTTP头名称: Pragma
HTTP头值: no-cache
优先级: 10
```

**添加Expires头：**
```
规则类型: 目录
规则内容: /wp-json/bjt/v1/cart
操作: 设置  
HTTP头名称: Expires
HTTP头值: Thu, 01 Jan 1970 00:00:00 GMT
优先级: 10
```

#### **3.3 为其他动态API添加相同的响应头**

重复上述步骤，为以下API路径添加相同的防缓存响应头：
- `/wp-json/bjt/v1/auth`
- `/wp-json/bjt/v1/order`
- `/wp-json/bjt/v1/user`
- `/wp-json/bjt/v1/login`

### **第4步：参数过滤配置**

#### **4.1 进入参数过滤页面**
```
左侧菜单：性能优化 → 参数过滤
```

#### **4.2 配置参数保留**
```
选择：○ 过滤参数 ● 保留参数

保留参数列表：
┌─────────────────────────────────────┐
│ _t                                  │
│ _cb                                 │
│ timestamp                           │
│ cache_buster                        │
│ _cache_buster                       │
│ t                                   │
│ version                             │
│ v                                   │
└─────────────────────────────────────┘

点击"确定"保存
```

### **第5步：回源配置优化**

#### **5.1 进入回源配置页面**
```
左侧菜单：回源配置 → 回源请求头
```

#### **5.2 添加回源请求头**
```
点击右上角"添加"按钮

配置项填写：
┌─────────────────────────────────────┐
│ 操作类型: ● 设置 ○ 删除              │
│ 自定义回源请求头名称: Cache-Control   │
│ 自定义回源请求头值: no-cache         │
│ 匹配规则: /wp-json/bjt/v1/cart*     │
└─────────────────────────────────────┘

点击"确定"保存
```

### **第6步：高级优化配置**

#### **6.1 开启智能压缩**
```
左侧菜单：性能优化 → 智能压缩
状态: 开启
```

#### **6.2 配置页面优化**
```
左侧菜单：性能优化 → 页面优化
HTML优化: 开启
CSS优化: 开启  
JavaScript优化: 开启
```

#### **6.3 设置访问控制**
```
左侧菜单：访问控制 → Referer防盗链
类型: 白名单
规则: 
- eorder.lockedair.com
- *.eorder.lockedair.com
- localhost
- 127.0.0.1
空Referer: 允许
```

### **第7步：缓存刷新**

#### **7.1 进入缓存刷新页面**
```
左侧菜单：刷新缓存 → 缓存刷新
```

#### **7.2 执行目录刷新**
```
刷新类型: ● 目录刷新 ○ URL刷新

输入刷新目录：
┌─────────────────────────────────────┐
│ https://eorder.lockedair.com/wp-json/bjt/v1/cart │
│ https://eorder.lockedair.com/wp-json/bjt/v1/auth │
│ https://eorder.lockedair.com/wp-json/bjt/v1/order │
│ https://eorder.lockedair.com/wp-json/bjt/v1/user │
│ https://eorder.lockedair.com/wp-json/bjt/v1/login │
└─────────────────────────────────────┘

点击"提交"执行刷新
```

## **🚨 故障排除**

### **问题1：购物车操作仍然不生效**

**可能原因：**
- 配置优先级不正确
- 缓存刷新不彻底
- 浏览器本地缓存

**解决方案：**
1. 检查缓存规则优先级（动态API应为最高）
2. 执行全站缓存刷新
3. 清除浏览器缓存并硬刷新（Ctrl+F5）

### **问题2：API请求仍然返回304状态码**

**可能原因：**
- HTTP头配置未生效
- 回源配置有问题

**解决方案：**
1. 重新配置HTTP头管理
2. 检查回源配置
3. 联系阿里云技术支持

### **问题3：静态资源加载变慢**

**可能原因：**
- 缓存规则配置过于宽泛
- 优先级设置错误

**解决方案：**
1. 检查静态资源缓存规则
2. 确保只有动态API不缓存
3. 优化静态资源缓存时间

### **问题4：配置生效时间较长**

**说明：**
- CDN配置通常5-10分钟生效
- 缓存刷新可能需要等待

**解决方案：**
1. 等待10-15分钟再测试
2. 使用强制刷新测试
3. 联系阿里云确认配置状态

## **🎯 最佳实践建议**

### **配置原则**
1. **精确匹配** - 只对必要的API路径禁用缓存
2. **优先级明确** - 动态API优先级最高
3. **定期验证** - 每周检查配置状态
4. **备份配置** - 记录所有配置项

### **性能优化**
1. **静态资源长期缓存** - CSS/JS/图片设置1年缓存
2. **API分层缓存** - 产品数据5分钟，动态数据不缓存
3. **压缩优化** - 开启Gzip压缩
4. **HTTP/2支持** - 确保启用HTTP/2

### **安全考虑**
1. **防盗链保护** - 设置Referer白名单
2. **IP访问控制** - 必要时限制来源IP
3. **HTTPS强制** - 全站HTTPS跳转
4. **安全头设置** - 添加安全相关HTTP头
