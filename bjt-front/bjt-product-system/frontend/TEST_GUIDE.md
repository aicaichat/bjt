# BJT前端集成测试使用指南

## 🚀 快速开始

### 安装依赖
```bash
cd frontend
npm install
```

### 运行测试
```bash
# 运行集成测试
npm run test

# 运行所有测试
npm run test:all
```

## 📝 可用的测试命令

### 主要测试命令

| 命令 | 描述 | 输出 |
|------|------|------|
| `npm run test` | 运行主要集成测试 | 真实的业务逻辑验证 |
| `npm run test:real` | 运行真实测试（同上） | 与test命令相同 |
| `npm run test:home` | 运行首页测试 | 首页功能验证 |
| `npm run test:all` | 运行所有测试 | 完整测试套件 |

### 开发测试命令

| 命令 | 描述 | 状态 |
|------|------|------|
| `npm run test:integration` | 运行集成测试框架 | 🚧 开发中 |

## 🚨 常见问题解决

### 1. 测试脚本未找到错误
```bash
npm error Missing script: "test"
```
**解决方案**: 确保在 `frontend/` 目录下运行命令

### 2. 测试文件不存在
```bash
测试文件不存在: /path/to/test/file
```
**解决方案**: 检查测试文件路径和TypeScript配置

### 3. 测试执行超时
```bash
测试执行超时
```
**解决方案**: 检查网络连接和模拟API响应时间

## 📈 测试报告说明

### JSON报告格式
测试完成后会生成JSON格式的详细报告：

```json
{
  "summary": {
    "totalTests": 6,
    "totalPassed": 6,
    "totalFailed": 0,
    "successRate": "100.0%",
    "testType": "INTEGRATION_TESTS"
  },
  "details": [
    {
      "test": "testPageLoad",
      "status": "pass",
      "duration": 145
    }
  ]
}
```

### 报告字段说明
- **summary**: 总体测试统计
- **details**: 各测试用例详细结果
- **testType**: 测试类型标识
