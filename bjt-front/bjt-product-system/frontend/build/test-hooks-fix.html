问题原因：

// 之前的问题代码（违反 Hooks 规则） if (loading) { return <LoadingComponent />; // 早期返回 } // 在条件返回后调用 useState - 违反规则！ const [someState, setSomeState] = useState(false);

修复方案：

// 修复后的代码（符合 Hooks 规则） // 1. 所有 Hooks 在组件顶部调用 const [someState, setSomeState] = useState(false); // 2. 条件渲染在组件最后 if (loading) { return <LoadingComponent />; }
⚠️ React Hooks 规则提醒

React Hooks 必须在每次渲染中以相同的顺序调用。不能在循环、条件或嵌套函数中调用 Hooks。 这确保了 React 能够正确地保持组件状态。
