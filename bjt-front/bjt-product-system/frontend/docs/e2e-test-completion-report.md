  - 移动端设备模拟
  - 自动启动开发服务器

## 🚀 如何开始使用

### 1. 快速验证
```bash
cd frontend
npm run test:e2e --project=chromium --grep="应该正确加载首页"
```

### 2. 运行特定测试组
```bash
# 运行首页测试
npm run test:e2e e2e/tests/home.spec.ts

# 运行机器页面测试
npm run test:e2e e2e/tests/machines.spec.ts

# 运行用户流程测试
npm run test:e2e e2e/tests/user-flow.spec.ts
```

### 3. 调试模式
```bash
# 调试首页测试
npm run test:e2e:debug e2e/tests/home.spec.ts

# 调试特定测试用例
npx playwright test --grep "应该正确加载首页" --debug
```
