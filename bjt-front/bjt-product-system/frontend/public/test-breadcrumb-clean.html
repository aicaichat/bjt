⚪ 现在的设计（简洁主题）

  • 灰色边框：1px solid #e5e7eb
  • 简洁阴影：rgba(0, 0, 0, 0.1)
  • 纯白背景：#ffffff
  • 无毛玻璃效果
  • 简洁清爽，与页面更协调
