🎨 混合布局设计 - Header + Sidebar

设计特点：

  • Header包含Logo、搜索框、语言切换、购物车、用户信息
  • Sidebar包含导航菜单，支持多级展开
  • 搜索功能突出显示，用户体验优先
  • 响应式设计，移动端适配
  • 清晰的视觉层次和功能分离

🔍 搜索功能演示

搜索框特性：

  • 位于Header中央，突出显示
  • 支持实时搜索和回车提交
  • 响应式设计，移动端自适应
  • 聚焦时有视觉反馈
Header功能区域：
语言切换、购物车（带数量徽章）、用户信息（头像+用户名）都集中在Header右侧，便于用户快速访问。

📱 响应式演示

PC端操作：

  • 点击侧边栏右上角的 "×" 按钮可以收起/展开导航
  • Header始终显示，包含所有功能项
  • 搜索框居中显示，易于访问

移动端操作：

  • Header保持显示，但搜索框和按钮会适当缩小
  • 侧边栏默认隐藏，点击左上角汉堡菜单显示
  • 点击遮罩层关闭侧边栏
设计优势：
1. 搜索功能突出，用户容易找到
2. 常用功能（语言、购物车、用户）集中在Header
3. 导航菜单独立在侧边栏，不干扰主要内容
4. 响应式设计，适配各种设备
