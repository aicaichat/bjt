🔧 实施步骤

  1. 备份当前代码

    保存现有的卡片布局代码，确保可以回滚

    // 备份 renderMachinesTable 函数 const renderMachinesTableBackup = renderMachinesTable;

  2. 创建列表布局结构

    使用CSS Grid实现12列布局，包含表头和列表项

    // 新的列表布局结构 <div className="bg-white rounded-lg shadow-sm border border-gray-200 overflow-hidden">   <div className="bg-gray-50 border-b border-gray-200 px-6 py-4">     <div className="grid grid-cols-12 gap-4">       <div className="col-span-1 text-center">选择</div>       <div className="col-span-1 text-center">图片</div>       <div className="col-span-2">型号</div>       <div className="col-span-2">名称</div>       <div className="col-span-1 text-center">电压</div>       <div className="col-span-1 text-center">箱装</div>       <div className="col-span-1 text-center">托盘</div>       <div className="col-span-1 text-center">价格</div>       <div className="col-span-1 text-center">库存</div>       <div className="col-span-1 text-center">数量</div>       <div className="col-span-1 text-center">操作</div>     </div>   </div>

  3. 迁移功能逻辑

    将现有功能迁移到列表布局，保持所有交互功能

    // 保持所有原有功能 - 选择功能：保持单选按钮 - 图片显示：缩小为48x48px - 产品信息：型号、名称、电压等 - 价格显示：保持价格格式 - 库存信息：保持库存标签 - 数量选择：保持数量调整 - 操作按钮：规格说明、更多信息、购物车

  4. 响应式优化

    适配不同屏幕尺寸，确保在各种设备上都有良好的显示效果

    // 响应式断点 @media (min-width: 1024px) {   .list-header-grid {     grid-template-columns: 60px 80px 1fr 1fr 100px 80px 80px 120px 100px 120px 120px;   } } @media (max-width: 1023px) {   .list-header-grid {     grid-template-columns: 50px 60px 1fr 1fr 80px 60px 60px 100px 80px 100px 100px;   } }

  5. 测试验证

    确保所有功能正常工作，包括选择、查看、购买等操作

    // 测试要点 - 选择功能是否正常 - 图片显示是否正确 - 价格和库存信息是否准确 - 数量调整是否有效 - 操作按钮是否可点击 - 响应式布局是否正常
