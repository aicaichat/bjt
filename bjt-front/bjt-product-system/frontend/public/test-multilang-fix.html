🌍 多语言切换修复测试

📋 测试说明

本测试验证Cart、Order、PO页面的产品名称多语言切换功能是否正常工作。

修复前问题：使用复杂的CartFieldUnifier.getProductName导致中英文切换异常

修复方案：使用简单的getSimpleProductName函数，避免复杂回退机制

📊 测试结果统计

🔧 修复对比

修复前 (CartFieldUnifier.getProductName)

// 复杂回退机制 + 英中文映射 static getProductName(item: any, language: 'zh' | 'en' = 'zh'): string { // 多层回退逻辑 const sources = [item.name_zh, props.name_zh, item.name, ...]; // 英文名称强制映射为中文 if (nameStr && /^[A-Za-z0-9\s\-().,]+$/.test(nameStr)) { const chineseName = ProductNameMapper.mapToChineseName(nameStr); if (chineseName && chineseName !== nameStr) { return chineseName; // ❌ 导致语言切换异常 } } }

修复后 (getSimpleProductName)

// 简单直接的字段映射 export function getSimpleProductName(product: ProductLike, language: 'zh' | 'en' = 'zh'): string { if (language === 'zh') { // 中文：优先name_zh，然后name，最后model return product.name_zh || product.name || product.model || '商品'; } else { // 英文：优先name_en，然后name，最后model return product.name_en || product.name || product.model || 'Product'; } }
