🔧 运输信息API修复验证

📋 修复说明

问题：订单API不返回shipping_address字段，导致PO页面运输信息显示为默认值。

修复方案：修改后端API的prepare_item_for_response方法，当shipping_address为空时提供默认运输信息。

预期结果：所有订单API响应都包含shipping_address字段，前端可以正确显示运输信息。
