🔧 运输信息API修复验证

📋 修复说明

问题：订单API不返回shipping_address字段，导致PO页面运输信息显示为默认值。

修复方案：修改后端API的prepare_item_for_response方法，当shipping_address为空时提供默认运输信息。

预期结果：所有订单API响应都包含shipping_address字段。

🧪 API测试

🔄 使用说明

  1. 点击"测试订单列表API"按钮检查订单列表是否返回运输信息
  2. 点击"测试订单详情API"按钮检查单个订单详情是否包含运输信息
  3. 查看测试结果，确认所有订单都有shipping_address字段
  4. 如果测试通过，前端OrderList到PO页面的运输信息传递应该正常工作
