# BJT产品系统 - 文件上传目录

此目录用于存储用户上传的文件，包括：

## 目录结构
- `accessory/` - 配件图片
- `consumables/` - 耗材相关文件
  - `images/` - 耗材图片
- `host/` - 主机图片
- `machines/` - 设备相关文件
  - `images/` - 设备图片
  - `pdfs/` - 设备PDF文档
- `spare_parts/` - 备件图片
- `documents/` - 其他文档

## 重要说明
- 此目录中的用户上传文件不会被Git跟踪
- 在服务器部署时，请使用 `scripts/sync-uploads.sh` 脚本来保留现有文件
- 目录权限应设置为 755，文件权限应设置为 644

## 备份策略
- 定期备份此目录中的文件
- 在代码更新前自动创建备份
- 保留最近5个备份版本
