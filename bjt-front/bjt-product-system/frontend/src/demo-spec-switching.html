`spec_imperial` varchar(255) COMMENT '规格参数(英制)',

🎯 技术实现说明

1. 配置文件简化

在 cartDisplayFields.ts 中只需配置 spec 字段：

export const SPARE_PART_FIELDS = {
  order_page: [
    'part_number',
    'name',           // 智能多语言切换
    'spec',           // 🎯 智能公制英制切换
    'unit',
    'pcs_per_box',
  ]
};

2. 自动字段映射

CartFieldUnifier.getFieldValue() 自动处理：

  • 公制模式: spec → 数据库 spec 字段
  • 英制模式: spec → 数据库 spec_imperial 字段

3. 智能回退机制

如果 spec_imperial 为空，自动回退到 spec 字段
