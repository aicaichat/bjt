## 页面功能

### 主要功能
1. **订单列表显示**：显示用户的所有订单
2. **状态筛选**：全部、待支付、已支付、已发货、已完成、已取消
3. **搜索功能**：支持按订单号或商品名称搜索
4. **日期筛选**：支持按日期范围筛选订单
5. **订单详情**：展开查看订单中的商品列表
6. **操作功能**：
   - 待支付订单：可以取消订单或去支付
   - 其他状态订单：可以导出PO单或查看详情

### 技术特性
- **错误处理**：API失败时自动回退到Mock数据
- **加载状态**：显示加载指示器
- **响应式设计**：支持移动端和桌面端
- **类型安全**：完整的TypeScript类型定义

## 使用方法

### 访问页面
- 直接访问：`http://localhost:5173/orders`
- 通过导航菜单访问

### 前置条件
- 用户必须已登录
- 如果未登录，会自动重定向到登录页面

### 数据来源
1. **优先级1**：尝试从API获取真实数据
2. **优先级2**：API失败时使用本地存储的订单数据
3. **优先级3**：最后使用Mock数据作为回退
