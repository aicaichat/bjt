# P2_60 - 在页眉上，增加搜索入口，根据料号、关键词能搜索出商品结果，在一个搜索结果页面展示结果，并且结果根据主机、配件、耗材、备件，分类分区展示，单条结果的排版和选型页的结果排版保持一致，有气泡展示详细信息，有一样的跳转按钮；有库存、加入购物车等按钮；

## 需求描述
在页眉上，增加搜索入口，根据料号、关键词能搜索出商品结果，在一个搜索结果页面展示结果，并且结果根据主机、配件、耗材、备件，分类分区展示，单条结果的排版和选型页的结果排版保持一致，有气泡展示详细信息，有一样的跳转按钮；有库存、加入购物车等按钮；
