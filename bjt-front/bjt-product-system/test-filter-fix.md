# 耗材页面筛选功能修复记录

## 修复内容

### 1. 添加了映射关系
- **形状ID到数据值的映射**：
  - MEX -> pillow (气泡枕)
  - MEY -> pillow (开口气泡枕)
  - MFB -> bubble (葫芦膜)
  - MFC -> tube (气枕膜)
  - MFF -> bubble (葫芦膜)

- **材质筛选**：直接比较，因为UI选项ID和数据值一致

### 2. 修正了字段路径
- **型号筛选**：使用 `item.app_model` 字段（兼容性）
- **形状筛选**：使用 `item.bag_type` 字段
- **材质筛选**：使用 `item.material` 字段
- **数值筛选**：使用对应的 `_met` 字段（thickness_met, width_met, length_met, net_weight_kg）

### 3. 改进了数值比较
- 添加了 `extractNumber` 函数来安全提取数值
- 使用容差比较（0.01）来处理浮点数精度问题

### 4. 增加了调试日志
- 打印当前筛选条件
- 打印数据样本的关键字段
- 为每个筛选条件添加了不匹配的日志
- 显示最终筛选结果统计

### 5. 修正了默认值
- 将材质默认值从 'hdpe' 改为 'all'，避免默认筛选

## 验证步骤

1. **打开浏览器开发者工具**，查看控制台日志
2. **访问耗材页面**，观察：
   - 是否显示"【筛选条件】"日志
   - 是否显示"【数据X】"日志
   - 是否显示"✅ [筛选结果]"日志

3. **测试各个筛选条件**：
   - 选择不同的机器型号
   - 选择不同的形状
   - 选择不同的材质
   - 观察控制台是否有"🔍 [XXX筛选] 不匹配"的日志

4. **验证筛选结果**：
   - 筛选后是否有数据显示
   - 数据是否符合筛选条件
   - 分页是否正常工作

## 预期结果

- 筛选功能应该能正确过滤数据
- 控制台应该显示清晰的调试信息
- 不同筛选条件组合应该返回正确的结果
- 重置筛选应该显示所有数据
