🔧 翻译调试说明

这个页面用于调试翻译键值问题。请按以下步骤操作：

  1. 确保前端开发服务器正在运行 (npm run dev)
  2. 打开浏览器开发者工具的控制台
  3. 访问耗材页面: http://localhost:5173/consumables
  4. 在控制台中运行以下测试命令
🧪 控制台测试命令
测试翻译函数是否可用:
typeof window.i18next !== 'undefined' ? '✅ i18next 可用' : '❌ i18next 不可用'
测试当前语言:
window.i18next?.language || '未知语言'
测试库存状态翻译:
window.i18next?.t('ui.stockStatus.out', { ns: 'consumables' }) || '翻译失败'
测试备用翻译路径:
window.i18next?.t('stockStatus.out', { ns: 'consumables' }) || '翻译失败'
检查翻译资源是否加载:
window.i18next?.getResourceBundle('zh', 'consumables')?.ui?.stockStatus || '资源未加载'
强制重新加载翻译:
window.i18next?.reloadResources().then(() => console.log('✅ 翻译资源重新加载完成'))
🔍 可能的解决方案
1. 清除浏览器缓存
按 Ctrl+Shift+R (Windows) 或 Cmd+Shift+R (Mac) 强制刷新
2. 重启开发服务器
在终端中按 Ctrl+C 停止服务器，然后运行 npm run dev
3. 检查翻译文件路径
确认 frontend/src/i18n/locales/zh/consumables.json 文件存在且格式正确
4. 检查i18n配置
确认 i18n 配置正确加载了 consumables 命名空间
📋 预期结果
正确的翻译结果:
中文: "暂时缺货"
英文: "Out of Stock"
错误的显示:
显示原始键名: "ui.stockStatus.out"
