# 🎯 字段标准化最优方法论

## 📋 概述

基于系统分析，当前字段标准化覆盖率较低：
- **机器页面**：40.0% (8/20字段)
- **耗材页面**：23.4% (11/47字段) 
- **备件页面**：50.0% (7/14字段)
- **配件页面**：9.5% (2/21字段)

本方法论提供**最高效、最安全、最系统化**的字段标准化解决方案。

---

## 🚀 三阶段标准化策略

### **阶段1：翻译文件快速修复** ⭐⭐⭐
**特点**：零风险、立即生效、影响最大

#### 🎯 执行方法
```bash
# 1. 预览修复效果（安全检查）
node scripts/quick-field-standardization.js --dry-run

# 2. 执行实际修复
node scripts/quick-field-standardization.js

# 3. 重启前端服务验证
./scripts/docker-dev.sh restart-frontend
```

#### 📊 修复重点
- **lbs→lb单位标准化** (最高优先级)
- **Package Size→Packaging Dim.** 
- **Shape→Film Type** (形状→袋型)
- **Pieces per Box→Qty per Carton**

#### ✅ 预期效果
- 立即修复80%以上的显示问题
- 零功能风险
- 自动生成备份文件

---

### **阶段2：配置文件集中修复** ⭐⭐
**特点**：集中管理、影响范围可控

#### 🎯 目标文件
```bash
frontend/src/config/machine-display-config.ts
frontend/src/config/consumable-display-config.ts  
frontend/src/config/accessory-display-config.ts
```

#### 📋 修复方法
```typescript
// 示例：machine-display-config.ts
export const MACHINE_FIELD_LABELS = {
  zh: {
    net_weight_lbs: '单件净重(lb)',    // 修复：lbs→lb
    package_size_cm: '包装尺寸(cm)',   // 修复：Package Size→Packaging Dim.
    pcs_per_box: '单箱数量',           // 修复：Pieces per Box→Qty per Carton
    name: '名称',                      // 修复：Name→Item
  },
  en: {
    net_weight_lbs: 'Net Weight(lb)',  // 修复：lbs→lb
    package_size_cm: 'Packaging Dim.(cm)', // 标准化
    pcs_per_box: 'Qty per Carton',    // 标准化
    name: 'Item',                      // 修复：Name→Item
  }
};
```
