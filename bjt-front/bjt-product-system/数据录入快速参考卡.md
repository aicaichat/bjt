## ✅ 标准格式

### 📝 产品名称
```
✅ HP LaserJet Pro M404n
❌ " HP LaserJet Pro M404n "  ← 不要首尾空格
❌ HP@LaserJet#Pro           ← 不要特殊符号
```

### 💰 价格
```
✅ 2599.99
❌ ￥2,599.99  ← 不要货币符号和逗号
```

### 🔗 网址
```
✅ https://www.company.com
✅ /products/123           ← 推荐相对路径
❌ www.company.com         ← 缺少http://
```

## 📋 录入前检查（每次必做）

- [ ] 删除首尾空格
- [ ] 删除 `'` `"` `;` `<` `>` 字符
- [ ] 价格只有数字和小数点
- [ ] 电话格式正确
- [ ] 邮箱格式正确

---

## 🔍 Excel批量导入步骤

1. **清理数据**：删除 `'` `"` `;` 等字符
2. **删除合并单元格**
3. **另存为CSV格式**（UTF-8编码）
4. **让技术人员验证**：`./validate-data.sh 文件名.csv`
