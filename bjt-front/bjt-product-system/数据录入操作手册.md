## 🚫 绝对不能输入的字符

### ❌ 这些字符会导致系统错误，严禁使用：

| 字符 | 名称 | 为什么不能用 | 后果 |
|-----|------|-------------|------|
| `'` | 单引号 | 会破坏数据库 | 系统崩溃 |
| `"` | 双引号 | 会破坏数据库 | 系统崩溃 |
| `;` | 分号 | 会破坏数据库 | 系统崩溃 |
| `<` `>` | 尖括号 | 网页安全风险 | 页面显示异常 |
| `\` | 反斜杠 | 系统字符冲突 | 数据错误 |

### ⚠️ 特别注意：
- **输入任何内容前，先检查有没有上面这些字符**
- **如果Excel里有这些字符，先删除再导入**
- **复制粘贴的内容也要检查**

## ✅ 正确的数据格式

### 📝 产品名称和型号

#### ✅ 正确示例：
```
HP LaserJet Pro M404n
佳能 EOS-5D Mark IV
联想 ThinkPad X1 Carbon
```

#### ❌ 错误示例：
```
❌ " HP LaserJet Pro M404n "     ← 前后有空格
❌ HP  LaserJet  Pro             ← 中间有多个空格  
❌ HP@LaserJet#Pro               ← 有特殊符号
❌ HP"激光"打印机                ← 有双引号
```

### 💰 价格

#### ✅ 正确格式：只能是数字和小数点
```
2599.99
1500
399
15999.50
```

#### ❌ 错误格式：
```
❌ ￥2599.99        ← 不要货币符号
❌ 2,599.99         ← 不要千位分隔符
❌ 2599.999         ← 小数点后最多2位
❌ 2599元           ← 不要单位
```

### 📦 数量和备件规格

#### ✅ 正确格式：数量选择中必须使用英文逗号
```
1,2,3,5,10          ← 英文逗号分隔
50,100,200          ← 英文逗号分隔
1个,2个,5个,10个     ← 如果有单位，英文逗号分隔
```

#### ❌ 错误格式：
```
❌ 1，2，3，5，10      ← 中文逗号（系统无法识别）
❌ 50，100，200       ← 中文逗号
❌ 1个，2个，5个      ← 中文逗号
❌ 1 2 3 5 10        ← 空格分隔
```

#### 🏷️ 备件类型分类（isconsumable字段）：
```
✅ 正确的值：
0  →  不显示备件（该备件不会在前端显示）
1  →  易损/耗材（需要经常更换的零件）
2  →  非易损/非耗材（标准备件，不易损坏）

❌ 错误的值：
3, 4, 5 等其他数字
true, false（不能用布尔值）
易损, 耗材（不能用中文）
```

#### ⚠️ 特别提醒：
- **备件数量选择必须用英文逗号 `,` 不能用中文逗号 `，`**
- **输入法切换到英文状态输入逗号**
- **复制粘贴时特别检查逗号类型**
- **isconsumable字段只能填0、1、2，其中0表示该备件不显示给用户**

### 📱 电话号码

#### ✅ 正确格式：
```
010-12345678        ← 座机：区号-号码
13812345678         ← 手机：11位数字
021-87654321        ← 座机格式
```

#### ❌ 错误格式：
```
❌ +86 138-1234-5678    ← 不要+86和空格
❌ 138 1234 5678        ← 不要空格分隔
❌ (010)12345678        ← 不要括号
```

### 📧 邮箱地址

#### ✅ 正确格式：
```
zhang.san@company.com

```

#### ❌ 错误格式：
```
❌ 张三@company.com      ← 不能有中文

❌ zhangsan@            ← 不完整
```

### 🔗 网址链接

#### ✅ 正确格式：
```
https://www.company.com/product     ← 完整网址
http://localhost:8080/admin        ← 本地网址
/products/detail/123               ← 内部链接（推荐）

```

#### ❌ 错误格式：
```
❌ www.company.com          ← 缺少http://
❌ company.com/产品         ← 不能有中文
❌ javascript:alert()      ← 危险代码
```

## 🔍 常见问题解决

### 问题1：输入后系统报错"数据格式错误"
**原因：** 可能包含了禁用字符  
**解决：** 检查是否有 `'` `"` `;` `<` `>` 等字符，删除后重新输入

### 问题2：价格显示不正常
**原因：** 价格格式不对  
**解决：** 确保只有数字和小数点，删除￥、元、逗号等

### 问题3：电话号码保存失败
**原因：** 电话格式不符合要求  
**解决：** 使用 010-12345678 或 13812345678 格式

### 问题4：页面显示乱码
**原因：** 输入了特殊字符  
**解决：** 检查是否有 `<` `>` 等字符

### 问题5：搜索找不到刚录入的数据
**原因：** 可能有多余的空格  
**解决：** 重新录入，注意去除首尾空格

### 问题6：备件数量选择无法保存或显示异常
**原因：** 使用了中文逗号而不是英文逗号  
**解决：** 将所有 `，` 替换为 `,`（切换到英文输入法输入逗号）

### 问题7：备件录入后在系统中看不到
**原因：** isconsumable字段设置为0（不显示）  
**解决：** 将isconsumable字段改为1（耗材）或2（非耗材）

### 问题8：isconsumable字段保存失败
**原因：** 输入了错误的值（如3、true、"耗材"等）  
**解决：** 只能输入0、1、2三个数字

## 📊 Excel批量导入注意事项

### 🚨 导入前必须做的事：

1. **检查格式**
   - 确保每列数据类型一致
   - 删除合并的单元格
   - 检查没有公式，只有数值

2. **清理数据**
   - 删除所有 `'` `"` `;` `<` `>` 字符
   - 去除多余空格
   - 价格列只保留数字

3. **保存格式**
   - 另存为CSV格式
   - 选择UTF-8编码

### ✅ Excel数据清理步骤：

1. **第一步：全局查找替换**
   - 查找 `'` 替换为空（删除单引号）
   - 查找 `"` 替换为空（删除双引号）
   - 查找 `;` 替换为空（删除分号）
   - 查找 `，` 替换为 `,`（中文逗号改为英文逗号）

2. **第二步：清理空格**
   - 选中所有数据
   - 格式 → 单元格 → 对齐 → 去除首尾空格

3. **第三步：检查价格列**
   - 确保价格列只有数字
   - 删除￥、元、逗号等符号

4. **第四步：保存文件**
   - 文件 → 另存为 → CSV格式
   - 编码选择UTF-8
