## 二、加速技巧与注意事项

### 1. 提高AI输出质量的技巧

- **提供详细上下文**: 每个请求都包含之前实现的相关组件链接
- **分段请求**: 复杂功能拆分为多个小请求
- **精确需求描述**: 使用具体而非抽象的语言描述需求
- **视觉参考**: 提供设计图片或截图
- **迭代改进**: 对AI输出进行审查，然后提出具体修改指示

示例:
```
请参考之前实现的Button组件样式(链接)，优化Modal组件的关闭按钮样式，
使其符合整体设计语言。关闭按钮应为圆形，使用浅灰色背景，
悬停时变为深灰色，并带有缩放动画。
```

### 2. 常见陷阱与解决方案

| 潜在问题 | 解决方案 |
|---------|---------|
| 样式不一致 | 要求AI遵循已建立的设计系统，提供具体变量名 |
| 组件间集成问题 | 明确说明组件间接口和数据流，要求使用已有接口 |
| TypeScript类型错误 | 要求AI提供完整类型定义，并检查类型兼容性 |
| 响应式问题 | 明确指定各断点需要的样式变化 |
| 冗余代码 | 要求AI遵循DRY原则，识别可复用逻辑 |
